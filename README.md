# 兰斯10 杀戮尖塔Mod

当前为 Godot 三层节点地图、战斗与部队编制原型，包含原版素材、界面、技能动画与音效。可直接运行根目录的 `Rance.exe`；程序使用 Git LFS 保存，克隆后需要通过 `git lfs pull` 获取完整程序。

目前已制作：

- 卡牌百科、部队编制、部署数值与共用设置；原版绿色滑入菜单及窗口、声音、动画设置页。
- 三层 30/28/26 行节点地图、虚线路线、原版羊皮纸与尖塔 2 节点图标、原版风格领队/HP/勋章 HUD。
- 独立初始卡组、怪物与事件 TXT 池、前五场弱怪、节点入口自动存档、连续战斗损伤、层间推进。
- 战斗准备、敌方行为预告、AP与技能使用限制、回合推进及重开。
- 通用连击节奏、伤害预测、双方延迟血条与扣血动画。
- 14种异常的实际效果、原版图标与施加动画、混乱行动红叉、点击说明和MISS反馈。
- 7张异常测试卡，每张两个技能，各给对方附加一种异常2回合。
- 兰斯与里克的必杀演出，以及演出播放设置。
- TXT管理的支援系统：自动攻击、无敌结界、自爆/攻击封锁体质、军师、物理/魔法阵、蓄力与抗性；复用原版支援栏、动画和音效。
- 最大HP百分比恢复/失去、领队DOWN与替换，以及17张配套测试卡和4个测试BOSS。
- 原版 WIN 搜刮界面、三种稀有度宝箱开封动画、普通/精英五选二与 Boss 三选一、TXT 卡池和共享稀有偏移。
- 原版商人立绘与动画、地图背景与地毯滑入展示、8 张卡牌 / 3 件遗物的商店，贝壳金币与五折商店遗物。

新游戏入口：标题选择「从头开始」，以 Lv42 兰斯出征；有进行中的存档时显示「继续游戏」。初始持有 99 金币，普通怪、精英与 Boss 胜利分别获得 5–10、15–25、50–60 金币。当前怪物池使用现有素材的临时团子变体，事件、商店与奖励提供基础流程；正式内容继续通过 TXT 配置扩展。

商店测试入口：反引号打开控制台，输入 `shop`，`gold 100` 增加 100 个贝壳。商品支持「详情」和「查看升级」；右键 / Esc 或「离开商店」返回。商人下方的「请商人降价」使用原版按钮素材，目前点击无操作。战斗掉落贝壳在 WIN 搜刮栏点击领取后入账。价格、遗物池与存档行为见 [商店与金币](docs/商店与金币.md)。

测试入口：在「百科大全 → 卡牌」部署领队，按反引号打开控制台并输入 `battle 宝箱团子`。该怪物基础HP为1000、基础AT为200、物理与魔法抗性各50%。支援测试可用 `battle 支援测试BOSS`，基础HP20000、AT20、抗性0；各测试卡技能与其他测试BOSS见下方支援规范。

源码项目入口为 `project.godot`。本地工作区修改卡牌、技能或其他资源后，可双击项目上一级目录的 `一键编译并运行.bat`，重新生成并启动 `Rance.exe`。这个编译工具及测试输出位于游戏仓库外，使用方法和日志位置见 [快速编译运行](docs/快速编译运行.md)。
