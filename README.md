# 兰斯10 杀戮尖塔Mod

当前为 Godot 战斗与部队编制原型，包含原版素材、界面、技能动画与音效。可直接运行根目录的 `Rance.exe`；程序使用 Git LFS 保存，克隆后需要通过 `git lfs pull` 获取完整程序。

目前已制作：

- 卡牌百科、部队编制、部署数值与共用设置。
- 战斗准备、敌方行为预告、AP与技能使用限制、回合推进及重开。
- 通用连击节奏、伤害预测、双方延迟血条与扣血动画。
- 14种异常的实际效果、原版图标与施加动画、混乱行动红叉、点击说明和MISS反馈。
- 7张异常测试卡，每张两个技能，各给对方附加一种异常2回合。
- 兰斯与里克的必杀演出，以及演出播放设置。

测试入口：在「百科大全 → 卡牌」部署领队，按反引号打开控制台并输入 `battle 宝箱团子`。测试怪物基础HP为1000、基础AT为200、物理与魔法抗性各50%。完整新游戏地图、抽取、存档和支援系统尚未接入。

制作说明：[卡牌与技能](docs/卡牌与技能制作规范.md)、[战斗与怪物](docs/战斗与怪物制作规范.md)、[异常效果](docs/异常效果制作规范.md)、[异常测试卡牌](docs/异常测试卡牌.md)、[伤害计算公式](docs/伤害计算公式.md)、[必杀演出](docs/必杀技演出说明.md)。

源码项目入口为 `project.godot`。本地工作区修改卡牌、技能或其他资源后，可双击项目上一级目录的 `一键编译并运行.bat`，重新生成并启动 `Rance.exe`。这个编译工具及测试输出位于游戏仓库外，使用方法和日志位置见 [快速编译运行](docs/快速编译运行.md)。
