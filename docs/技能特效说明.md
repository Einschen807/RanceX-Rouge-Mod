# 技能特效

45组原版技能特效统一放在 `assets/effects/`，一组一个目录，目录名保留原版文件名。每组有 `animation.json`、原图纹理和 `audio.ogg`；`catalog.json` 是运行时索引。素材抽取记录及测试文件仅保存在项目外的 `test/effects_port/`。

## 在技能中调用

`data/skills.txt` 的第5个字段是特效名。只填写名称，不填写Godot路径：

```text
{ 20, "突击－零－", 1, 1, "", "", 0, 1, 100, 0, 0, 0, 0, 0, "", 0, 1, "攻击(1倍)" };
{ 1093, "死爆", 1, 3, "魔法／暗魔法攻击", "", 1, 1, 200, 0, 0, 0, 0, 0, "", 0, 2, "魔法(2倍)rAP累计" };
```

例如 `"手里剑"`、`"手里剑.flat"` 都会调用“手里剑”；`"魔法／炎魔法攻击"` 和 `"魔法/炎魔法攻击.flat"` 都会调用同一组炎魔法。全角 `／` 是资源目录名的一部分。

第6个字段是独立的必杀技演出名，留空 `""` 不播放cut-in，不影响第5字段的技能特效和默认规则。填写名称后查找 `.tscn` 场景，详见 [必杀技演出说明](必杀技演出说明.md)。

填写名称时，直接使用该组动画和音效，不再叠加默认特效。“是否大招”不会覆盖显式名称，显式指定大版本时需填写名称中的 `（大）`。未知名称会在日志中提示，并使用类型默认值，避免动画空缺。特效只控制表现，不会改变技能的伤害、治疗、AP等数值规则。

## 留空时的默认值

| 技能类型 | 默认特效 |
|---|---|
| 1 近战 | 突袭攻击 |
| 2 远程 | 远程攻击 |
| 3 魔法 | 按角色炎、冰、雷、光、暗属性选择对应魔法攻击 |
| 4 准备 | 附加效果 |
| 5 恢复 | 附加效果 |
| 6 特殊 | 附加效果 |

大招字段为1时，默认使用同名 `（大）` 版本。无属性角色或没有属性资料的敌方魔法，按原版规则在五种魔法中随机选择。原版非攻击技能的增益使用“附加效果”、减益使用“负面效果”；目前准备／恢复／特殊统一默认附加效果，未来新增减益技能时可直接填写 `"负面效果"` 或 `"负面效果（大）"`。

进攻特效显示在对手位置，准备／恢复／特殊显示在己方位置。主动技能、回合开始自动技能、敌方技能共用播放器；被动技能没有独立释放过程。敌方条件不满足时仍只消耗预告图标，不播放技能特效。

## 扩展资源

新增 `assets/effects/<名称>/animation.json` 和纹理即可按名称调用；同目录 `audio.ogg` 可选。索引中没有的新目录同样可以调用。动画使用本项目的FLAT转换JSON格式，保留 `version`、`fps`、`timelines`、`libraries`、`textures`。ELK数据位于type=7的library的 `emitter` 中。

伤害结算优先使用 `impact_time`；没有该字段时查找原版“伤害”脚本标签，再回退时间轴80%的位置。`play_duration` 规定展示时长；“魔人无敌结界”“极限值突破失败”这两组原本停帧/循环的状态素材，在技能调用中展示1秒后清除。延长持续状态应由以后状态系统管理，不通过让一次技能永久阻塞来实现。

播放倍速沿用战斗设置；音效保留原音高和原时长。动画结束后回收实例。播放器保留原图、时间轴和151组粒子参数；三维倾斜使用正交投影，随机采样使用Godot RNG，尚不是与原引擎逐像素一致的实现。FLAT二进制字段参考 [libsys4格式实现](https://github.com/nunuhara/libsys4/blob/master/src/flat.c)；默认选择规则核对自本地原版 `BattleAcitonEffect::Find/GetDefault/GetFlatBaseName` 和 `NonAttackSkillEffect::Find`。
