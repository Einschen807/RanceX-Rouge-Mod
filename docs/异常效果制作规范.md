# 异常效果制作规范

基础效果编号 `10～24` 可直接写入 `data/skills.txt` 的任意一组 `效果1/数值1`、`效果2/数值2`、`效果3/数值3`。不依赖技能描述或自定义脚本。25～29预留给后续异常，不再用于配置/解除支援。

数值 `1～9` 表示给释放者的对方附加相应回合数；`11～19` 表示给释放者自身附加个位数回合数。例：`10,3` 给对方3回合燃烧；`10,13` 给自身3回合燃烧。`0`、`10`、`20` 及更大的数值无效，数据加载时会报告错误。

同种异常重复施加时，剩余回合相加，上限9。回合数不是强度层数，不会重复乘算异常效果。按原版，每方同时最多3种不同异常；栏满时可叠加已有异常，但不能添加第四种异常。异常按照附加顺序排列。

| 编号 | 异常 | 实际效果 |
| --- | --- | --- |
| 10 | 燃烧 | 受到炎属性攻击的伤害增加50% |
| 11 | 混乱 | 己方回合开始时随机封锁一个可用行动，显示原版红叉 |
| 12 | 虚弱 | 攻击力降低20%；受到攻击的伤害增加20% |
| 13 | 毒 | 己方回合开始扣除当前HP的5%，向下取整且至少保留1 HP |
| 14 | 诅咒 | 剩余回合归零时扣除当前HP的20%，向下取整且至少保留1 HP |
| 15 | 黑暗 | 非远程攻击有25%概率未命中；远程攻击抵消这项惩罚，沉睡目标必中 |
| 16 | 反再生 | 阻止HP恢复 |
| 17 | 恐怖 | 联合部队每轮AP恢复减少1；敌方每轮随机封锁一个行动 |
| 18 | 沉睡 | 无法行动；受击必中、伤害增加100%，受到伤害后解除 |
| 19 | 冰冻 | 受到冰属性攻击的伤害增加50% |
| 20 | 触电 | 受到雷属性攻击的伤害增加50% |
| 21 | 信息阻断 | 隐藏受影响一方的HP、扣血数字、数值日志和伤害预测 |
| 22 | 即死预告 | 剩余回合归零时HP归零，正常结算胜负 |
| 23 | 致命伤 | 攻击力降低50% |
| 24 | 纯净 | 附加时清除其他异常，不自然扣层；每阻挡一次其他异常附加消耗1层 |

纯净使用相同目标编码：`24,2`给予对方2层，`24,12`给予自身2层。重复施加叠加，上限9；清除其他异常不消耗新获得的纯净层数，也不触发被清除的诅咒/即死预告到期效果。异常栏满也可施加纯净，因为先清除其他异常；混乱/恐怖已产生的行动封锁同时解除，已实际行动的标识不变。纯净不会清除支援、DOWN或其他局内增益。

纯净按异常附加命令逐项消费，作用于双方及主动/自动技能。一次给予9回合燃烧也只消耗1层；一次技能按燃烧、冰冻、触电顺序附加三项时，2层纯净阻挡前两项，纯净消失后触电正常附加。三个独立行为依次施加也是同一规则。额外回合不会消耗纯净层数，伤害也不会消耗纯净。

复用已授权“日不落”MOD的小/大纯净图标，以及原版异常附加、解除和聚焦演出。点击异常图标使用现有压暗说明框，无悬停说明。“纯净测试”的上/下技能分别给予自身/对方2层纯净；“纯净阻挡测试”的上技能一次依序给予燃烧、冰冻、触电各2回合，下技能单独给予燃烧2回合。

燃烧、冰冻、触电不造成持续伤害。对应属性来自攻击卡牌的元素；自定义伤害命令可显式指定 `element`（0无、1炎、2冰、3雷、4光、5暗）。异常、局内增益和减攻统一在额外增伤项中相加，详见 [伤害计算公式](伤害计算公式.md)。

双方分别在自己的行动回合结束时扣除一次剩余回合，因此给敌方1回合沉睡，会先阻止敌方当轮行动，再到期解除。自身1回合异常作用于当前己方回合。毒和混乱在受影响一方回合开始时结算；本回合中途附加时不补做回合开始结算。敌方混乱和恐怖共用一次随机行动封锁；沉睡优先阻止全部行动。

连击只重复伤害命令，异常命令执行一次；命令按照三个效果槽的顺序执行。悬停预测使用独立状态和随机数副本，不会改变异常回合、真实随机数、行动封锁或日志。

双方异常栏复用原版55×68图标、66像素间距、回合底牌和数字素材；附加时播放原版FLAT中的图标变换与黑圆粒子，解除时播放原版解除光效。点击图标在该图标上方显示原版黑底金框的紧凑说明，标题为异常名，正文为实际效果；复用怪物行为说明的全屏暗幕与点击关闭流程，点击任意位置、右键或Esc返回，关闭时不触发底层技能或结束回合。混乱封锁的卡牌与敌方行动使用原版红叉；卡牌额外保留原版晕眩动画。MISS使用原版动画，停留后淡出并清理，支持双方及所有战斗倍速。没有增加悬停说明。

原版依据为项目旁的 `Rance10.ain` 中 BadConditionGroup、BadConditionView、伤害计算器及战斗场景结算代码，以及解包的 BadConditionView Pact、状态异常图标和FLAT。施加必定成功：现有技能编码只提供目标和回合，没有另设原版的异常概率、异常抗性、免疫与特定角色特殊规则。毒使用原版常规5%规则，没有接入原版困难条件下的10%变体。

验证脚本、资源来源清单、截图、视频和报告均位于外部 `F:/RanceX Slay The Spire/test/status_effects`。
