# 快速编译运行

项目上一级目录的 `一键编译并运行.bat` 可直接双击。先保存 `Rance/data/cards.txt`、`Rance/data/skills.txt` 等文件并关闭正在运行的游戏，再双击BAT。脚本会导出完整游戏、替换 `Rance/Rance.exe` 并自动启动，不需要打开Godot编辑器。技能演出、场景及其他资源修改也会一起打包。

首次编译或新增素材时需要导入资源；之后只修改TXT会复用现有Godot资源缓存，请勿删除项目的 `.godot` 缓存。

## 输出与失败处理

- 当前游戏：`Rance/Rance.exe`。
- 上一次成功替换前的程序：项目外的 `test/quick_build/Rance.previous.exe`，每次成功更新时覆盖。
- 编译日志：`test/quick_build/build.log` 和 `godot.log`，每次编译覆盖。
- 临时导出：`test/quick_build/Rance.exe`，成功更新时移动到游戏目录；导出或替换失败时保留用于排查。

导出失败不会替换原程序。游戏仍在运行时，脚本会提示先保存进度并关闭游戏；按任意键后再次检查，不会强制结束游戏。

## 可选参数

```bat
REM 只编译，不启动游戏
"一键编译并运行.bat" --build-only

REM 自动化调用：只编译，失败或完成时均不等待按键
"一键编译并运行.bat" --build-only --no-pause
```

默认编译工具位于项目外的 `test/tools/godot_runtime/Godot_v4.7.2-stable_win64_console.exe`，请保留这个目录。需要改用其他位置的同版本Godot时，在运行BAT前设置环境变量：

```bat
set "RANCE_GODOT_EXE=D:\Godot\Godot_v4.7.2-stable_win64_console.exe"
"一键编译并运行.bat"
```

脚本使用 `Rance/export_presets.cfg` 中现有的 `Windows Desktop` 导出预设和发布模板。若移动项目或模板文件，需要同步更新预设中的模板路径；具体错误可查看编译日志。脚本按自身所在目录定位项目，不依赖命令行当前目录。
