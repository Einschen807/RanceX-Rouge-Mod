# 战斗与怪物制作规范

怪物通用加载脚本位于 `scripts/monster/monster_catalog.gd`，各怪物专用脚本放在 `scripts/monster/<唯一识别名>/`，例如 `scripts/monster/斗神Σ/`。共用战斗系统位于 `scripts/battle/`；完整目录规则见 [脚本目录结构](脚本目录结构.md)。

## 测试入口

打开标题页「百科大全 → 卡牌」，选好领队。按键盘左上角的 `~` /反引号打开控制台，输入：

```text
battle 宝箱团子
```

指令的参数是怪物**识别名**。百科使用当前百科模型中的全部基础卡牌，领队、星级和已选加成沿用当前编制。标题没有卡组时指令不执行。战斗准备阶段可再次打开编制，选择领队后点击战斗开始；左下角MENU位于准备遮罩与WARNING图案上方，可直接打开共用设置，返回后仍处于准备阶段。右键/Esc可关闭控制台、设置、技能说明和编制；战斗主界面不会因此退出。解析面板由解析按钮独立开关。

普通游戏编制传入真实持有的 `TroopState` 即可使用同一战斗；没有打开编制时，正常游戏流程调用 `BattleManager.register_run(state)` 提供实际卡组。退出该游戏流程时调用 `register_run(null)`。当前项目尚未实现完整新游戏地图、抽取和存档业务，控制台不会凭空创建真实持有牌。

「查看升级」只属于编制视图。战斗始终查询实际领队记录；预览不会把基础牌替换为强化牌，真实持有的 `+` 卡仍使用自身技能和数值。

## 怪物：data/monsters.txt

```text
{ "显示名", "唯一识别名", "立绘名", "背景名", 基础HP, 基础AT,
  物理抗性, 魔法抗性, 种类, 行为ID, "解析说明", 限伤百分比 };
```

固定12字段（旧11字段兼容为不限伤），数值必须是整数。显示名可重复，识别名唯一且非空。HP大于0，AT不小于0，抗性范围0～100；抗性50代表对应类别的伤害减少50%。种类1普通怪、2精英怪、3BOSS。超过32位的HP由64位整数读取、双精度结算，HP界面不缩写为“亿”。

立绘名对应 `assets/monsters/<立绘名>.png`，背景名对应 `assets/battle/backgrounds/<背景名>.png`。推荐原版1920×1080含透明留白的立绘，通用立绘自动播放轻微呼吸缩放；宝箱团子使用原版分层FLAT的身体、手臂、宝箱和光效循环。新增素材要优先使用原版，缺少时以已有素材制作，保留原有资源与导入配置。

宝箱团子为种类1普通怪，当前测试数值为HP 1000、AT 200、双抗50。准备画面统一使用参考图的红色WARNING原版时间线；是否BOSS由怪物数据决定。

## 行为：data/monster_behaviors.txt

```text
{ 1,
  "开局追加=9404，9604,20",
  "行为1", 20, 21, "回合数2倍数",
  "行为2", 20, "敌方HP50以下",
  "行为3", 20, ""
};
```

第一项是唯一正整数行为ID，第二项固定为双引号包裹的 `"开局追加=技能编号1，技能编号2,技能编号3"`。支持中英文逗号混用与任意数量技能；没有追加时填写 `"开局追加="`。编号必须是存在于 `data/skills.txt` 的正整数，不允许空编号。

开局追加在点击战斗开始后、第一回合支援和领队自动技能之前，按顺序强制执行一次。支持所有技能ID及其基础、自定义效果，不消耗AP或自然行为次数，不检查技能的行动类型、条件和自动概率；释放记录仍计入技能使用次数。战斗重开从准备快照恢复，再重新执行一次，不重复叠加。例中的9404先为怪物配置无敌结界，9604追加10%护盾，20发动突击。`battle 开局测试boss` 可验证开场自带结界、后续只有突击的效果。

之后重复“行为名称字符串、任意数量技能ID整数、条件字符串”。行为数和每个行为的技能数没有固定上限；技能0是空占位，不执行。技能必须存在于 `data/skills.txt`。每回合开始按文件顺序选择第一个满足条件的行为，不合并后续行为。没有匹配行为时待机。

行为条件和技能条件共用安全的声明式解析器，不运行脚本。完整写法与边界规则见[技能与怪物条件规范](技能与怪物条件规范.md)：支持COMBO、AP、双方支援/异常数量与指定名称、双方HP百分比、回合数及倍数。友方固定为玩家方，敌方固定为怪物方，以上/以下包含边界；`&&`为与、`|`为或、`()`优先。旧英文比较式及单个`&`仍兼容。

选择行为后，怪物按技能ID顺序执行；每个技能仍检查自身释放条件和次数限制，失败仅跳过该技能。怪物不消耗AP，允许同一行为连续释放多个技能。怪物生命周期独立于玩家卡牌，重复进入战斗不会污染玩家的技能次数。

## 斗神Σ：一层遗迹BOSS

已加入一层遗迹BOSS池，也可输入 `battle 斗神Σ`。基础HP10000、AT500、物理及魔法抗性0，立绘为原版斗神，背景为云间天光。

行为7开局追加9901配置永续带锁支援70「斗神体质」。自然行为如下：

| 回合 | 顺序 |
| --- | --- |
| 1 | 9903配置玩家永续带锁支援71「瞄准目标」，本轮不攻击、不随机选人 |
| 2、5、8…… | 9907突袭1倍 → 9907突袭1倍 → 9906斗神重击 |
| 3、6、9…… | 9908突然一拳1倍并施加虚弱1层 → 9909稳固核心获得最大HP的8%护盾 → 9906斗神重击 |
| 4、7、10…… | 9910强化：本场锁定人数增加1，不攻击 |

第2回合开始，每个玩家回合由瞄准目标自动技能9904随机选择不重复的有效在场领队。初始1名，强化后依次2、3……，最多7名且不超过可选人数。强化从下一玩家回合瞄准生效，随机抽选沿用战斗随机源。每名目标显示独立靶心，行动后继续显示，随卡牌抬升移动；换下或DOWN时保留其余目标，并从未锁定的有效领队中补足。

敌方回合开始，在玩家行动记录清空之前，统计被瞄准且未行动结束的有效领队人数N。N>0时配置敌方支援72「锁定目标」并替换玩家的瞄准支援；全部行动则不配置，斗神重击跳过。重击条件保留为 `敌方支援存在[锁定目标]`，伤害倍率为3+2N，因此漏1/2/3人分别为5/7/9倍，而非指数翻倍。伤害为一次攻击，正常应用抗性、增伤、护盾、结界与命中规则。

重击成功执行后，即使MISS或被阻挡，也恢复瞄准支援。「锁定目标」可解除，解除会恢复瞄准并阻止本轮重击。敌方回合结束时也恢复残留的锁定支援，保证强化轮或攻击受阻后，下一轮仍能正常重新瞄准，不继承旧重击许可。两个目标支援互斥，不受支援栏满影响。8%护盾按现有规则在怪物下回合开始时消失。

新增强化和人数加成沿用斗神专属自定义技能接口，未新增基础效果编号。普通攻击、虚弱与护盾复用基础效果。锁定列表和强化人数纳入预估副本与战前快照，预估不改变真实随机序列，重开清空成长并回到首轮。

## 共享技能与结算

`SkillRuntime` 检查AP、条件、概率和次数，`SkillBaseEffects`/`SkillCustomEffects` 产生命令，`BattleState`消费命令。描述文字只展示，不用于推断效果。

基础效果：0空、1伤害（100为1倍AT）、2连击（整数为攻击次数）、3恢复最大HP百分比、4失去最大HP百分比（3、4负数作用于对方）、5本方领队DOWN、6～9额外抗性/增伤、10～24异常（24纯净）、25～29预留、30～34配置/解除支援、40玩家护盾、41怪物护盾（军师、结界、体质等使用自定义接口）、35本场AT增益、36按AT倍率治疗。特殊命令可指定 `target: "self"` 或 `"opponent"`；完整编码见 [支援与DOWN制作规范](支援与DOWN制作规范.md)。异常数值1～9给对方，11～19给自身，同种剩余回合相加，上限9；纯净层数不自然减少。完整编号、实际效果及结算时机见 [异常效果制作规范](异常效果制作规范.md)。

玩家近战/远程使用怪物物理抗性，魔法使用魔法抗性；同时应用当前部队对应增伤率。伤害保留浮点精度，UI生命值向上取整显示，生命比率四舍五入显示整数百分比。友方比率放在数值左边，敌方放在右边；共用原版数字字形及渐变。角色名称、HP标题、数字分行排列。解析不再重复展示基础HP。

## 回合、AP与换人

战斗中央沿用原版Round/VS底图和黄色渐变数字，居中只显示当前回合，不显示斜杠或最大回合数。敌方行动预告图标底边统一位于红色透明长条的下边框之上，大招图标的外框也留在长条上方；保留原版450像素渐变长条，左端与敌方HP条的转折起点竖直对齐，右侧斜边靠近Round底图。

玩家本场最大HP取点击“开始战斗”时首发阵容的综合HP，包含当时已有的HP加成。准备阶段调整编制会更新HP预览；开始后上限固定，战斗中换人、移除领队、DOWN自动替补或部队数值变化均不重算，也不因换人降低当前HP。恢复、失去HP、护盾和HP百分比条件统一使用本场固定上限。重开回到准备阶段后，可调整首发阵容并在再次开始时重新确定上限。

AP默认上限6，AP最大值强化后10。战斗初始3AP；后续每回合开始自然恢复2AP，AP恢复强化后偶数回合恢复3AP、奇数回合恢复2AP。恢复不超过上限。主动技能成功才扣AP、消耗该领队行动次数和关闭换人窗口；失败不改任何这些状态。

每个领队每回合一次主动行动，两个技能共享限制。回合开始自动技能不占主动次数。操作模式一直接点击上下技能；模式二悬停显示原版高亮边框；先点击卡牌进入连续查看，移动到其他卡牌直接切换技能描述，离开卡牌区后结束查看，再次进入需重新点击。展开后点击技能释放，已行动卡牌仍能查看，但不能再次释放。

两种模式均在刷新时立即显示技能本身的禁用状态，不需要先悬停。动画播放中的临时输入锁只拦截释放，不使其他原本可用的技能变灰。AP惩罚处于临时上涨时用原版橙色数字、AP字样和箭头；本局累计和本场累计的初始费用为白色，发生累计后才使用紫色素材。状态按角色、技能槽位与技能ID共同记录，同角色两个同名技能和不同角色的相同技能都独立累计。限制一次技能在对应生命周期内使用后显示“已”，并保持不可释放。可换人时隐藏轮数，冷却中只叠加原版白色渐变数字，“Round后”直接沿用按钮底图，不重复绘制文字。

第一回合不允许战斗中换人。默认下一窗口为第6回合，之后可换人时第一次成功主动技能把下一窗口设置为当前回合+5；更换领队加成把间隔改为1，从第2回合起每回合开始可换。编制返回时，与打开前相比新增的领队标记行动结束，原领队仅换位置保留原来的行动状态；同一窗口允许继续整理。

每个我方命中的伤害命令累积1点Combo，MISS和无敌结界／抵挡阻挡不累积，命中护盾仍累积。每点已有Combo为我方接下来对敌方造成的倍率伤害增加10个百分点的额外增伤率，与强化、必杀及其他额外增伤加算。每段先读取已有Combo计算伤害，结算后再加1点；零Combo的1倍3连击依次为1倍、1.1倍、1.2倍，悬停预测同样逐段模拟。连击只复制效果编号1的倍率伤害，治疗、增益及追加自定义效果各执行一次。AP、行动次数、技能使用次数和自爆体质回调按整次技能计算，必杀cut-in也只播放一次。当前Combo上限13，达到后保持13（+130%），进入敌方回合清零；敌方攻击不使用玩家Combo增伤。双方支援栏已接入，规则见 [支援与DOWN制作规范](支援与DOWN制作规范.md)。

攻击附带对敌方立即失去HP的效果时，倍率伤害与附加扣血分段更新血条和伤害数字，沿用原版扣血演出，两段间隔跟随战斗速度。附加扣血不重播攻击特效、不增加Combo、不重复扣AP或次数；整次技能结束后才处理行动结束回调与胜负。悬停闪烁仍按完整技能的总扣血预览，伤害公式、当前／最大HP百分比基准与护盾结算保持原有顺序。

结束该轮依次执行预告中的怪物技能，然后恢复AP并进入下一回合。敌HP归零胜利、玩家HP归零败北，第99回合结束超时。战斗内右键只关闭局部弹窗或卡牌查看，不回退到原编制。解析左侧的“重开”使用原版重新战斗图标和相同金色方形按钮，回到当前敌人的战斗准备阶段，恢复血量、AP、回合与本场状态，返还本场消耗的累计/一次限制，保留开战前的本局累计、当前队伍、速度和操作模式。动画期间不执行重开。

速度按钮默认3倍，循环1/2/3倍，对应初版播放速度的4/3、8/3、4倍（新版3倍等于此前2倍，各档同比放缓）；改变原版时间线、呼吸、粒子、动作补间和行动等待，不改变伤害、AP或次数。音效保留原始音高。玩家选择写入用户目录settings.cfg的battle/speed，重进战斗和重启游戏均保留。战斗MENU和标题设置打开同一个设置面板，音乐/音效分别控制既有Music/SFX总线。

操作模式和速度按钮保留原版图标并重新排入中文标题。解析使用原版帮助问号。敌方技能悬停只高亮对应图标，点击后显示原版金框说明并压暗全屏；再次点击任何位置或按右键退出，关闭点击不会触发下层按钮。

## 通用力量成长（所有怪物共用）

怪物需要随回合成长时，统一在行为技能列表中引用以下五个技能，不再为各怪物另写力量成长技能或脚本：

| 技能ID | 名称 | 本次增加层数 |
| --- | --- | --- |
| 9971 | 力量成长1 | 1 |
| 9972 | 力量成长2 | 2 |
| 9973 | 力量成长3 | 3 |
| 9974 | 力量成长4 | 4 |
| 9975 | 力量成长5 | 5 |

例如一个行为填写 `"成长后突袭",9972,9907,""`，会先增加2层力量，再发动现有突袭。也可在开局追加列表引用9971～9975。增长频率由怪物行为条件决定；力量支援本身不会自动增长。此功能不会自动修改现有怪物的行为配置。

力量支援ID为90，效果技能ID为9270。按用户确认使用技能ID自定义接口，无新增基础效果编号。每次在施法方增加层数；只有一个支援实例，永续带锁，普通驱散无效。每层物理、魔法额外增伤各+10个百分点，加入现有额外增伤乘区，不与军师相减，也不改变基础AT、百分比扣血或治疗。

力量Ⅰ为+10%，力量Ⅴ为+50%，力量Ⅹ为+100%；继续叠加没有人为层数上限。名称采用罗马数字，40以上使用现有字体支持的L/C/D/M，4000以上括号表示乘1000，例如力量(Ⅴ)为5000层。详情同步展示十进制层数和当前增伤。

首次配置遵守7个支援位置上限；已有力量在满栏时仍能继续叠加。支援层数随战斗快照复制，伤害预测不修改真实层数，重开恢复开战前状态，新战斗不继承上一场的力量。带锁沿用现有支援语义，不阻止明确无视锁的强制清空机制。

测试与日志：`F:/RanceX Slay The Spire/test/strength_20261020/`。
## 怪物逐段限伤

`data/monsters.txt` 最后一项为限伤百分比：整数0～100，0表示不限伤。斗神Σ为30，其余现有怪物为0。旧11字段记录按0兼容。

每段近战、远程、魔法倍率伤害（含支援和遗物攻击）在增伤与抗性结算后，按 `min(伤害, 怪物最大HP × 限伤% / 100)` 封顶，再处理护盾吸收。连击每段分别封顶，不限制整个技能的合计伤害；最大HP10000、限伤20时，四次足够高的攻击合计8000，低于2000的单段保持原伤害。不使用剩余HP计算。该规则不改变独立的直接失去HP、异常扣血和即死命令。
