# 卡牌强化与休息点

卡牌数据 `data/cards.txt` 中，普通版与强化版都按稀有度设置相同的基础 HP 和 AT：其他阵营的普通／罕见／稀有（稀有度1／2／3）为50／75／100，神魔阵营为75／100／125。神魔卡牌须勾选部队加成“神魔阵营解禁”才能编成领队；未解禁时沿用原版不可用遮罩，取消解禁会卸下已编成的神魔领队。百科也遵守该限制，首次进入卡牌总览时默认启用全部现有部队加成。

正常获取调用 `TroopState.acquire_card`：未持有时加入卡组，首次重复时原位替换成对应的 `+` 版本，持有强化版后每次重复增加 5 级。不同显示名的同角色卡仍是不同卡牌。原位替换保留获取顺序、等级、领队位置、DOWN 状态及 `card_settings` 实例设置；不会把普通版与强化版同时加入卡组。

强化通过 `TroopState.upgrade_card` 统一处理。`SkillRuntime.replace_card` 按技能槽迁移旧技能 ID 到新技能 ID 的本局使用次数、本场使用次数、上次使用回合与本回合行动状态。强化不能重置一次性限制或 AP 累计。未来的附魔等卡牌实例设置可加入 `card_settings`，自动随版本替换及检查点保存继承。

若强化改变 AP 类型（例如加奈美的本局一次变成本局 AP 累计），已经消耗的一次性限制仍通过 `SkillRuntime.inherited_limits` 保留，直到原有本场或本局限制的重置边界。AP累计（类型2）跨战斗保留，本局内AP累计（类型3）在新战斗恢复基础费用；强化时两份使用计数仍按原技能槽完整继承。该状态同时参与存档与战斗预测。界面继续复用原版卡牌、金框、按钮和提示框素材。

控制台 `upgrade` 默认提供 1 次强化，`upgrade x` 提供 x 次（正整数）。在部队编制界面选择卡牌后，左右对比当前卡和强化结果，默认展示技能描述，底部「确认强化」确认。预览不修改实际卡组，次数用完后自动关闭。中途退出需确认，已确认的非休息点强化保留。

已经是强化版（或没有 `+` 记录）的卡牌不能再次强化：选卡列表中叠加原版「无法选择」暗色遮罩，但仍可点击；点击后弹出原版 InformationDialog 样式提示（「シス／对话窗口／下地」底板、50% 黑色遮罩、无按钮），点击任意位置或右键 / Esc 关闭，不消耗强化次数。重复获取已强化卡时的 +5 级规则不变。

强化对比界面背景沿用百科的高斯模糊并压暗编制界面，标题使用原版设置页的金色花纹横幅，卡名使用原版项目底框，箭头为原版任务地图右箭头（金色、左右轻摆），按钮为原版宽 196 按钮。强化后卡牌的技能描述按升级预览规则把变化的数值标为柔和亮绿。打开时当前卡从列表位置飞到左侧、强化卡由左向右滑入，其余元素随后淡入；返回时整体淡出。确认后数据立即生效并播放锻造演出（约 1.7 秒，右键可跳过）：当前卡变暗，强化卡依次受到三下敲击（不显示锤子），每下在落点爆出一个白色火花点，外围一圈由四段断开的橙红弧线组成的光环向外扩散并淡出，同时细长的火星沿飞行方向四散后下落；卡牌下沉震动并闪亮，播放打铁声（三下音高分别 ×1.0／1.06／0.95）。第三下后播放原版「卡牌级别提升」音效，卡面金光一闪。之后淡出回到选卡；最后一次强化在演出结束后才关闭界面（休息点为黑屏转场到地图）。打铁声由工程外 `test/forge_rest_fx_20261023/make_strike_sound.py` 合成（参照用户提供的锻造音效视频测得的频谱与包络合成，未使用其音频：2～4.5 kHz 密集的不和谐金属泛音，起音频谱重心约 4 kHz，满幅保持约 0.1 秒后快速衰减、高频泛音余响最久，几乎不含低频；其下垫一层轻微的房间混响作为底色余音；原版音频包中没有合适的打铁声），火花点与火星图片由同目录 `make_spark_sprites.py` 绘制，休息点完成演出所用的原版音效由 `test/forge_rest_fx_20261023/prepare_assets.py` 复制。该界面不使用战斗中的 boost（卡牌強化 / 强化中）特效，两者是不同机制。素材来源与验证见工程外 `test/card_upgrade_ui_20261023/`。

`upgrade test` 仅限从标题百科大全进入的卡牌总览部队编制界面。第一次输入将本次总览的全部普通卡原位替换为强化版，再次输入则全部恢复普通版本，之后继续交替切换；版本切换保留当前等级、编制和技能状态，不增加等级。`battle 怪物识别名` 使用这份临时卡组，离开战斗返回本次总览时仍保留；退出卡牌总览后该实例被销毁，再次进入会重新建立普通卡组，开关也恢复关闭。此命令不修改卡牌目录、行军卡组或存档，在标题、行军、普通编制、战斗或其他弹窗界面不可使用。

休息点提供三选一：恢复最大生命值30%、强化1张卡、重置所有卡牌。回血不再重置卡牌；重置卡牌也不回血。“重置卡牌状态”统一表示恢复全部卡牌技能的使用次数、一次性限制及初始AP费用（清除跨战斗／本场AP累计与普通AP临时惩罚），由`TroopState.reset_card_states()`处理；卡牌版本、等级、编制与实例设置保留。满血时仍可独立选择重置。完成任一选项后结束该恢复点，强化选卡取消后返回三项菜单。

持有特殊遗物「生命之蛋 / 时间之蛋 / 大地之蛋 / 力量之蛋」时，休息点在三项下方额外出现「孵化」：一次孵化所有持有的蛋，蛋从遗物栏移除并分别获得「圣女 温丽娜小 / 塞菈库勒斯小 / 胡瑟苏娜小 / 贝泽爱小」（已持有时按重复获取规则处理）。持有任意圣女小版本（含 `+`）时额外出现「培养」：一次把所有小版本原位替换为大版本（`圣女 X小` → `圣女 X`，`圣女 X小+` → `圣女 X+`，没有大版本 `+` 记录时为基础大版本），保留等级、领队位置、DOWN 与实例设置，技能使用状态按技能槽迁移（`TroopState.replace_card_version`）。孵化与培养都占用本次休息，结果页「继续行军」或右键结束节点。

休息点界面为全屏「篝火休整」（`scripts/map/rest_site_screen.gd`）：背景是原版剧情背景「营地／夜」模糊压暗后铺满全屏，中央以原图（自带原版金色装饰框）按 0.92 倍展示，篝火与提灯位置叠加闪烁的暖光和少量火星。顶部标题横幅下显示「部队生命 当前/最大 比率%」，比率 ≥60% 绿色、30～60% 黄色、<30% 红色。底部为选项卡片：休息（恢复30%，标注实际回复量）、锻炼（强化卡牌）、整备（重置所有卡牌状态），以及按条件出现的孵化、培养；图标复用原版部队加成图标与蛋遗物图。进入时场景淡入、卡片依次上浮；悬停放大提亮。选择后其余卡片变暗，不弹结果框，而是播放完成演出后黑屏转场回到地图（演出中右键可跳过）：休息——篝火与提灯光芒增强、暖色光晕铺满画面、顶部生命值与比率滚动增长并浮出绿色「+N」，音效为原版「恢复」+「温暖的」；整备——图标旋转一周、两道金色光环扩散、浮出「所有卡牌状态已重置」，音效为原版「铠甲响声」+「抽卡」；孵化——蛋摇晃后碎裂为白光与火花，浮出获得的卡牌名，音效「裂痕」+「获得卡牌」；培养——图标弹起、金色光爆，浮出成长后的卡牌名，音效「级别提升」。选择前右键返回地图且休息点保持未完成。锻炼进入强化界面，取消后回到篝火界面；在休息点强化完成后不再淡回选卡，而是保留锻造画面并黑屏转场到地图。素材准备脚本与验证位于工程外 `test/rest_site_20261023/`。温丽娜、塞菈库勒斯、胡瑟苏娜的大小版本共6张已加入卡牌库（神魔阵营、稀有度0事件专用、暂无技能、无 `+` 版本），属性与原版一致。

默认强化1次，节点的`upgrade_count`可为未来特殊情况提供更多次数。未确认任何强化时退出直接回到休息点选项；确认部分强化后退出须确认撤销本次全部选择，恢复入口卡牌版本、等级、编制及技能状态，并返回休息点选项。全部次数确认后才完成节点。

选择界面、比较预览和退出弹窗都在 GUI 控件处理前支持共享 `ui_cancel`（右键或 Escape）。预览中返回先关闭比较，退出弹窗中返回则继续选择。强化期间其他控制台变更命令暂不可执行。
