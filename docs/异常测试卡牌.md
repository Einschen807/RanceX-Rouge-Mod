# 异常测试卡牌

在百科的卡牌列表中选择“异常测试01”至“异常测试07”并部署，进入测试战斗。七张卡分别属于前七个阵营，可同时编入部队。

每张卡的两个主动技能各给对方附加一种异常2回合，不造成直接伤害。初始消耗0AP，连续回合使用同一个技能时按通常规则增加1AP；每张卡每回合只能使用一个主动技能。基础HP和AT均为0，不增加阵营基础HP和AT贡献；部署数值仍按部队公式计算。卡面复用现有素材。

| 卡名 | 阵营 | 技能1（技能ID／效果编号） | 技能2（技能ID／效果编号） |
| --- | --- | --- | --- |
| 异常测试01 | 主人公 | 燃烧（9010／10） | 混乱（9011／11） |
| 异常测试02 | 利萨斯 | 虚弱（9012／12） | 毒（9013／13） |
| 异常测试03 | 赫尔曼 | 诅咒（9014／14） | 黑暗（9015／15） |
| 异常测试04 | 赛斯 | 反再生（9016／16） | 恐怖（9017／17） |
| 异常测试05 | 自由都市 | 沉睡（9018／18） | 冰冻（9019／19） |
| 异常测试06 | JAPAN | 触电（9020／20） | 信息阻断（9021／21） |
| 异常测试07 | 其他 | 即死预告（9022／22） | 致命伤（9023／23） |

异常栏最多同时容纳3种异常；同种异常叠加回合数，上限9。测试下一组时可以重开战斗，避免栏位已满。即死预告会在持续回合结束时使目标HP归零。

技能数据在 `data/skills.txt`。所有测试技能的效果数值为2；如需测试给自身施加异常，将对应数值改为12（自身2回合）。改数据后须重新导出EXE。
