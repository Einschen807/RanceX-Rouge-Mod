# 设置与伤害预览

## 两级原版菜单

标题设置、战斗 MENU、地图右上角齿轮和地图空白处右键，先打开仅右侧的绿色菜单。菜单使用原版 `シス／菜单／下地`、项目条纹、按钮图标和宽 400/196 的按钮 FLAT；从游戏右边缘用 0.24 秒缓出滑入，返回时用 0.18 秒缓入收回。

菜单从上到下为“放弃本局游戏”“返回标题界面”“指南”“设置”，右下角为“返回”。标题中不能再返回标题，没有进行中存档时也不能放弃本局；有暂停存档时可在标题菜单中放弃。“指南”保留按钮，当前点击无操作。返回标题保留入口存档；放弃删除本局主存档、备份、临时文件及内存快照，不清除设置。

点击“设置”进入原版棕金背景的全屏设置页，右侧仅有“窗口”“声音”“动画”和右下角“返回”，右上角保留原版 TITLE 按钮。窗口控制全屏，声音独立控制音乐、音效、语音，动画控制必杀演出播放方式。标题中 TITLE 不可用。原版背景、装饰线、滑条、按钮状态与选项卡资源位于 `assets/settings`，原始动画 JSON 保留在 `assets/settings/native`。

右键/Esc 在设置页返回绿色菜单，在绿色菜单返回原界面；输入在 `_input` 处理并消费，避免同一次右键穿透到地图或其他界面。所有菜单测试、截图、素材来源和导出产物位于工程外部 `test/native_settings`。

标题的设置按钮和战斗MENU共用同一个设置面板。音乐、音效、语音音量分别控制 Music、SFX、Voice 总线，三者独立；降到0时真正静音，调整后自动保存。兰斯、里克、谦信及后续必杀演出语音均走 Voice，其默认增益提高4 dB，设置中的100%对应提高后的音量。旧存档保留原音乐、音效音量，新语音项默认100%，不继承音效音量。新增“演出动画”板块，必杀演出使用三项互斥切换：不播放演出、每次播放演出、仅致命一击时播放。默认每次播放，选择写入 `user://settings.cfg`，重启后恢复。

“不播放”仅跳过必杀cut-in，普通技能特效和结算保留。“仅致命一击”在我方技能播放前，计算这次技能全部指令执行后的敌方HP，能击杀怪物才播放；连击合计可触发，未满足条件或不能释放的技能不触发。自动技能使用已经通过概率判定的本次指令，避免重复抽取。演出仍使用固定正常速度，战斗倍速不影响cut-in。

## 共用计算框架

`BattleForecast`复制BattleState和双方SkillRuntime状态，保留独立随机数状态，复用真实的技能释放及指令结算。部队和目录只读共享。`BattleState.damage_amount`是预览与结算共用的抗性、加成计算入口。预览不会修改实际HP、AP、行动标记、使用次数、日志、意图或随机数进度。

悬停可释放的我方伤害技能时，敌方血条中预计扣除的原生纹理段向黑色闪烁，模拟扣血后的空血条；旁边百分比显示预计释放后的剩余HP比例并同步闪烁；HP数字保持当前实际值。没有伤害、不能释放、鼠标移开、打开设置/弹窗/编制、开始行动或窗口失焦时恢复普通血条与百分比。两种操作模式共用技能悬停事件。技能释放、结束回合等过程重新创建按钮后，根据最近的鼠标位置恢复高亮与预览，鼠标无需先移开再移回。

双方实际扣血时，主血条立即更新，下方延迟血条保留原始纹理和轮廓，敌方使用暗灰红色、友方使用暗灰蓝色，增强与各自实血条的对比。它先原地停留0.40秒，再用0.18秒快速收回到实际血量；收回采用三次缓出曲线，起步快、到达时短暂减速。连续命中从当前显示的位置重新停留后收回，普通界面刷新不会重新开始动画；治疗和战斗初始化直接同步两个图层。右侧玩家血条保持原有方向和边缘对齐。若悬停时敌方延迟层仍在播放，先完整播放血条及受伤效果，保留实际HP百分比，仅立即显示技能/AP高亮；等延迟层动画真正结束，再按当前实际HP计算预计扣血和剩余百分比并开始闪烁。等待期间切换技能只保留最新预览，鼠标移开、失焦、打开设置/弹窗、开始行动或回合变化取消等待。

每次实际扣血还会用原版血条遮罩及竖纹素材，将本次损失区间从血条边界向上投射为白闪、红色和条纹光柱，然后向当前血量边界收窄淡出。敌我双方和任何连击共用此机制，效果随战斗倍速播放，连续命中重新触发而不累积残留。

解析框内，怪物描述下方显示白色的“本轮预计伤害：X%”。计算按照当前意图技能的执行顺序，累计对联合部队的伤害除以玩家最大HP；可反映先加攻击、后攻击及条件变化，超过最大HP的伤害比例可以超过100%。如真实流程会因死亡结束，则模拟也停止。敌方回合开始前显示整个计划，敌方行动过程中显示尚未执行的部分，包括当前连击尚未打出的伤害，换轮后重新计算。

战斗右上按钮排列为：解析在左，重开在右。设置支持共享ui_cancel（右键/Esc）返回，不增加技能悬停说明框。测试怪物宝箱团子基础HP为1000、基础AT为200，物理和魔法抗性仍各50%。
