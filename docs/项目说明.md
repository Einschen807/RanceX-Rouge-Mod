# 项目说明

双击同目录下的 `Rance.exe` 即可运行，不需要安装 Godot。
编辑项目时，用 Godot 4.7.2 打开 `project.godot`，按 F6/F5 运行。

脚本已按功能分目录，怪物专用实现位于 `scripts/monster/<怪物唯一识别名>/`。目录职责和新增脚本规则见 [脚本目录结构](脚本目录结构.md)。

界面以 1920×1080 为设计尺寸，默认窗口 1280×720；调整窗口会保持比例。
三个主按钮为「从头开始」「继续游戏」「百科大全」，底部左侧为「设置」。
「百科大全」打开同场景的百科叠加菜单，隐藏原菜单按钮、实时高斯模糊并压暗标题背景。
菜单包含「卡牌总览：查看所有的卡牌」「遗物收集：检阅所有的遗物」。
点击「返回」、按 Esc 或鼠标右键关闭百科并恢复主菜单焦点；标题动画和背景音乐保持连续。
鼠标右键统一代表 UI 返回，在卡牌、按钮和空白区域上都生效，每次退回一层；主菜单没有上一级时保持原处。
百科的金色边框、绿色纹理、卡牌、宝箱全部复用原版素材，未生成新美术。
卡牌入口的三张卡为：左侧黄色自由都市阵营志津香，中间绿色主人公阵营兰斯，右侧蓝色其他阵营希露。
背景高斯模糊强度已由 8 调整为 20（以设计分辨率的像素为基准）。
两个百科入口提供悬停和按压反馈，通过 `entry_selected(entry_id)` 发出 cards/relics 信号，
其中 cards 已接入共用部队编制界面的卡牌总览，自动展示统一数据库中的全部卡牌。
卡牌总览与百科之间使用黑屏淡入淡出；背景音乐持续播放，过渡期间屏蔽输入，避免重复切换。
遗物入口按稀有度分类展示，悬停显示原版金边描述框。
可用鼠标操作，也可用 Tab/方向键选择、Enter/空格按下。

卡牌总览支持十阵营切换、领队部署/替换/拖动下场、阵营HP/AT与综合数值统计，
以及卡面→HP/AT→技能描述的三态半翻转。包含34张启动样例卡牌、26个技能。
点击卡牌会快速移动至领队位置，空位依次按从左往右的第4、3、5、2、6、1、7格填入；同阵营替换保留原位置。
已上场卡牌再次点击不会重播动画。领队支持原尺寸拖动、空位移动、占位互换和就近吸附；拖回下方阵营区域下场。
上方领队仅在按住并实际拖动时半透明，单击、悬停、获得焦点及松手后均为正常透明度；拖动期间原槽位保留Not Set框。下方阵营卡牌保持正常透明度。领队默认卡面底部只显示AT，不绘制角色名称层。
阵营中已上场的卡牌带原版Leader字样动画和蓝色呼吸边框。阵营HP/AT包含领队，综合AT为所有可用卡牌AT的平均值乘牛车系数（默认5），综合HP保持领队出战HP合计及HP加成公式。
阵营切换仅对可见卡牌施加从左上到右下的逐张淡出/淡入，背景、阵营页签、领队和其他控件保持稳定；背景纹理直接切换。部队编制/部队加成切换保留快速淡出淡入。卡牌外框位于信息层下方。
已移除抢攻发生率、帮助按钮及悬浮说明；未明确要求时不新增悬浮说明。
编制界面使用原版国旗页签、数字字形、统计分支线、排序圆钮、卷轴和按钮状态动画；
部队加成与部队编制按钮紧邻排列，按要求移除了人物信息和指定加成项目。
卡牌统一在 `data/cards.txt` 创建，技能统一在 `data/skills.txt` 创建，卡面目录为 `assets/cards/`。
基础效果、技能条件、AP生命周期和所有创建规范见 [卡牌与技能制作规范](卡牌与技能制作规范.md)。
真实游戏复用同一编制场景并只传入已获得的卡牌。已实现战斗与怪物数据，百科编制中按 `~` 输入 `battle 宝箱团子` 可进入测试战斗；标题没有卡组时不执行。战斗使用实际牌，升级勾选仅预览。怪物与行为分别在 `data/monsters.txt`、`data/monster_behaviors.txt` 创建，详细规范见 [战斗与怪物制作规范](战斗与怪物制作规范.md)。抽取或读档流程尚未开放。

启动时直接从黑底标题动画开始，省去原版警告界面。红色 Rance 从左向右出现，
随后剑形标志出现、闪白、留下放大残影并显现地图，火焰依次带出「决战」。
约 2.53 秒开始淡入按钮，约 2.73 秒完成；点击或按 Enter 可跳过。
动画第 1 秒开始同时播放原版「标题商标」音效和标题背景音乐。
音乐按原版采样位置循环；正常结束动画时保留音效尾部，主动跳过时停止入场音效、保留音乐。
音乐与音效分别走 Music/SFX 总线，可在 `default_bus_layout.tres` 调整音量。
界面操作音效复用原版“系统／光标”“系统／点击”“系统／取消”，由常驻UIAudio管理并通过SFX总线播放。
首页四个按钮、百科入口、编制页阵营/排序/详情/模式/加成按钮及领队上场/换位已有音效；返回与卸下领队使用取消音。悬停或键盘焦点使用光标音，禁用按钮不响。
BGM 由常驻场景 `scenes/bgm_manager.tscn`（自动加载名 `BGM`）统一控制，只有一个音乐播放器。
切换游戏界面不会销毁音乐。以后各场景调用 `BGM.play_music(stream, track_id)` 切歌，
设置界面调用 `BGM.set_volume(0.0~1.0)` / `BGM.set_muted(bool)`；重复请求同一曲目保持播放位置。
动画复用了本机原版 FLAT 的图层、关键帧、透明度、颜色、循环信息和 14 帧火焰贴图，
进入标题后继续播放背景尘埃和标志循环。Godot 播放器实现了这套标题使用的二维子集；
已按你提供的原版启动视频逐帧对照，修正了嵌套图层顺序、裁剪对齐、颜色混合和菜单时机。
原视频使用了有损压缩，尘埃循环的初始相位也可能不同，因此不保证像素完全相同。

主要文件：
- `scenes/title_screen.tscn`：标题布局。
- `scripts/title/title_button.gd`：按钮视觉反馈，后续可连接业务动作。
- `scripts/title/title_screen.gd`：入场、跳过与菜单显示。
- `scenes/encyclopedia_overlay.tscn` / `scripts/encyclopedia/encyclopedia_overlay.gd`：同场景的百科叠加菜单、返回和焦点管理。
- `scripts/encyclopedia/encyclopedia_entry.gd`：两个百科入口及交互反馈。
- `shaders/gaussian_blur.gdshader`：横向、纵向两次高斯卷积；中间使用 BackBufferCopy 保证两个方向都生效。
- `scripts/title/title_audio.gd`：原版标题音效和背景音乐，按动画帧触发。
- `scenes/bgm_manager.tscn` / `scripts/audio/bgm_manager.gd`：全局唯一的 BGM 控制场景。
- `scripts/audio/ui_audio.gd`：原版界面音效、四声部播放池和共用按钮音效绑定。
- `scripts/animation/original_flat_player.gd`：原版二维图层时间线播放器。
- `assets/title/`：原版贴图与转出的时间线数据。

项目目录只保留游戏源码、素材、配置、说明及正式程序。
测试脚本、截图、对照视频、报告和素材来源清单统一放在项目外的 `F:\RanceX Slay The Spire\test`，不参与游戏运行。

重新导出时选「Windows Desktop」。当前预设引用本机解包工具目录中的官方 Windows
导出模板；换电脑后请安装匹配版本的 Godot 导出模板，并清空预设里的自定义模板路径。
`Rance.exe` 已内嵌资源包。以后增加业务功能时建议继续使用这个项目修改、导出。
