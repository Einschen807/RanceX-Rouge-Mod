# 遗物系统与配置

遗物是周目部队的全局增益，按获得顺序从左到右显示并执行。定义读取 TXT，库存、顺序和遗物计数器保存到部队及节点入口存档。计数器从获得遗物时的 0 开始，每个之后到来的我方回合开始累计一次，跨战斗保留；没有明确说明战斗结束清空的遗物不会自动重置。战斗重开恢复准备阶段的库存、顺序和计数进度，再重新执行开战效果。旧存档缺少计数器时从 0 补齐。

## 定义与遗物池

`data/relics.txt` 每条记录四个字段：

```text
{"遗物名称","图标文件名",1,"描述"};
```

图标存放于 `assets/relics/`，字段不写 `.png`。稀有度 1 普通、2 罕见、3 稀有、4 商店、5 特殊、6 援助。援助遗物同样不进入任何池，由开局援助选项获得，并在 `data/aids.txt` 中按人物登记归属，图鉴「援助」页签（粉色）按人物分节，见[援助制作规范](援助制作规范.md)。特殊遗物不进入默认遗物池和商店遗物池，只能通过控制台 `add relic`、事件指令（如 `choose relic`、`random relic`，见[事件制作规范](事件制作规范.md)）或今后专门设计的途径获得；图鉴新增「特殊」页签（淡紫色）。名称唯一；不存在的图标、错误类型、重复名称都会阻止部分数据进入游戏。遗物描述使用 TXT 原文。

`data/relic_pools.txt` 仅登记名字：

```text
{默认遗物池};
{商店遗物池};
```

可以追加新名称，使用 `RelicCatalog.pools` 或 `BattleManager.launch_relic("池名称")` 调用。默认池自动读取稀有度 1–3，普通、罕见、稀有的抽档权重为 50、33、17；商店遗物池自动读取稀有度 4 并等概率选择。已拥有的遗物不再掉落，TXT 不需要枚举池成员。

默认池现有普通、罕见、稀有三档，按 50% / 33% / 17% 抽档。当某一档没有可抽遗物时，重新抽档（代码使用等价的剩余权重归一化，不做无限循环）。所有候选都已拥有时返回“遗物池中没有尚未获得的遗物”，不会生成空奖励。

新增名称、图标、稀有度、描述只需编辑 TXT；描述与技能描述相同，小写 `r` 显示为换行。触发条件和遗物到技能的映射位于 `scripts/relic/relic_effects.gd`，实际攻击、配置支援等效果复用 `data/skills.txt` 的技能记录，游戏不解析自然语言描述来执行规则。当前忍法帖调用9800、妖怪宝具调用9801、郁金香2号调用9802、郁金香兵调用9803、郁金香3号调用9804、平实柠檬调用9805（效果24纯净，自身1层）、赫尔曼石墙调用9806（效果40护盾10%）、守护神调用9807（效果30配置支援60伤害抵挡）；塔罗柯发动机与3段喷射发动机共用技能0的AP+1回复；这些技能复用现有基础效果30（己方配置支援）和1（攻击），没有新增基础效果编号。

真实战斗按遗物栏顺序依次演出，并在技能特效的命中帧通过统一技能命令入口结算。郁金香播放远程攻击特效及音效，命中按正常攻击增加Combo；忍法帖和妖怪宝具播放配置技能特效，支援配置时沿用支援栏的添加动画和音效。遗物不消耗AP、不占用角色行动、不抬起角色卡牌。无演出的规则计算直接调用相同技能与结算入口，战斗重开会恢复遗物技能使用次数和计数器。

伤害抵挡（`data/supports.txt` 支援ID 60）是可解除、可累积、持续1回合的支援：配置后覆盖随后的敌方回合，在下一个本方回合开始时移除。所有配置伤害抵挡的技能与遗物（加奈美忍法帖、守护神、阴阳护盾及其强化版）都引用这同一个支援，新增相关技能时同样用效果30配置支援60，不要另建副本。每份只抵消敌方一段命中攻击后消失，三连击只消耗一份来抵消其中一段；未命中、HP 比例损失、异常伤害不消耗该支援。沿用真实战斗规则的预测会在副本中消耗支援，不改变玩家库存或战斗状态。

遗物顺序有实际影响，例如先配置军师再发动郁金香2号，攻击会计入军师加成；反向顺序则先发动攻击。周期计数显示本周期已累计回合，差 1 回合触发时持续闪烁发光，触发后回到 0；离开战斗后依然显示该进度和临近触发的提示。例如忍法帖在第一场战斗累计到 5，结束后保持 5，第二场战斗第一回合配置伤害抵挡并回到 0。战斗途中获得遗物从 0 开始，下一次我方回合开始才首次累计。

“战斗开始时”类遗物统一登记在 `RelicEffects.BATTLE_START`，在第 1 回合开始按遗物栏顺序发动，战斗重开会重新发动一次。飞马登记在 `PERIODS` 与 `AP_SPENT`，由 `BattleState.prepare_player_skill` 扣除 AP 后调用 `RelicEffects.ap_spent` 累计，不随回合累加；额外施放、自动技能和遗物技能不支付 AP，不计入。岩石花通过 `RelicEffects.status_capacity` 读取。图标来自 `素材/遗物/兰斯10/卡牌物品图`：岩石花使用 `稀有赫尔曼２`，守护神使用 `真·守护神`，飞马使用 `稀有赫尔曼１`，中元茶泡饭使用 `回避中元茶泡饭`。验证见工程外 `test/relic_batch_20261023/`。

必杀发生率与连击发生率（部队编制显示的两项）现已生效：每个我方回合开始，在自动技能之前各自独立按概率判定一次，成功则随机给 1 名尚未行动的可用领队一次必杀或连击（与基础效果 43/44 相同，本回合结束清除）。概率为 0 时不抽随机数，不改变既有随机序列。冰箱、旗帜和两把剑的规则集中在 `RelicEffects`（`fridge_carry`、`troop_rate_bonus`、`status_bonus`、`can_break_barrier`、`barrier_broken`），验证见 `test/relic_flags_20261023/`。

回合结束类遗物在 `RelicEffects.TURN_END_ROUNDS` 登记触发回合，由战斗界面在玩家点击「结束该轮」后、敌方回合开始前按遗物栏顺序演出；攻击使用当时的 Combo，随后进入敌方回合时 Combo 照常清零。若该攻击击败敌人，直接胜利，敌方不再行动。图标来自 `素材/遗物/兰斯10/卡牌物品图` 的 `郁金香兵`、`郁金香３号Ｈ`。验证见工程外 `test/relic_tulip_20261023/`。

男人的友情、医学全集、雷伊奖章、希尔琪奖章、瓦古奖章、侍从铠甲复用基础效果 1、3、18、40、42，没有新增基础效果编号；条件判断集中在 `RelicEffects`（`all_male`、`shield_bonus`、`player_damaged`，希尔琪奖章在 `turn_end` 按护盾比例判断）。图标取自 `素材/遗物/兰斯10/卡牌物品图` 同名文件。验证见工程外 `test/relic_medals_20261023/`。

## 控制台与界面

反引号打开控制台：

- `add relic 遗物名称`：获得指定遗物。
- `add card 卡牌名称`：获得基础卡牌；已有卡增加一颗强化星，不自动部署。
- `add medal 数量`：添加正整数数量的勋章，沿用部队升级规则。
- `help`：显示全部可用命令，控制台边框不列出命令清单。
- `relic`：打开默认遗物池宝箱。
- `relic 池名称`：打开已登记的指定遗物池。

优先操作当前战斗部队、可见的非百科编制、当前周目部队。标题界面没有部队时使用独立调试库存，不修改新游戏初始库存。宝箱与战斗互斥，已有宝箱时禁止再开宝箱或进入战斗。

宝箱黑底使用兰斯原版宝箱，悬停显示白色轮廓，点击播放原版开封动画，随后显示可点击领取的遗物。右键 / Esc 可返回。`TroopState.acquire_relic` 是统一领取入口，从任意来源获得遗物都会播放约 0.45 秒飞入顶部遗物栏的动画；库存不允许重复遗物。

顶部遗物栏距上边框 20 像素，右侧为战斗按钮留出空间，支持横向滚动，悬停显示名称及描述。百科的「遗物收集」页沿用原版设置页布局：棕金背景、上下金色栅线；右侧标题「遗物收集」下为「全部 / 普通 / 罕见 / 稀有 / 商店 / 特殊 / 援助」原版页签，各自显示件数，当前页签为蓝色；右下为原版宽 196「返回」按钮。左侧为按稀有度分节的高密度网格：每节以稀有度色标题、件数和原版金色点线分隔；遗物格为深色圆角底板加稀有度色细边（普通银灰、罕见蓝、稀有金、商店绿），图标下方显示名称，名称过长时自动缩小字号。每行固定 10 件、左对齐，一屏约容纳 65 件；超出时用鼠标滚轮或原版滚动条浏览，已用 134 件模拟遗物验证布局不溢出。切换页签时遗物格依次淡入（总时长封顶约 0.5 秒）。说明框默认显示在遗物下方；下方放不下（如最底部的特殊遗物）时改为显示在遗物上方（`RelicTooltip.show_beside`）。悬停仍使用兰斯原版金边说明框，右键 / Esc 返回百科入口。进入和返回均复用ScreenTransition黑屏过渡，过渡期间阻止重复切换。原始图标来自指定的 `素材/遗物/兰斯10/卡牌物品图`。

返回标题会解除本局部队及遗物栏的绑定，标题不显示持有遗物。正常返回保留入口存档，继续游戏时重新绑定恢复的部队；“放弃本局游戏”清除本局存档和备份后返回标题，新局不会继承遗物或计数器。

遗物图标悬停沿透明轮廓显示白色描边，在 0.12 秒内放大至 112%，移开恢复。闪烁使用同轮廓的白色底层，原图透明度最低降至 40%，保留颜色及细节后恢复，不产生图标外的光源圆圈。宝箱原版动画置于独立 CanvasLayer 71，奖励及不透明底的金边说明框在 CanvasLayer 72，避免箱盖或箱体遮挡。

## 遗物栏（折叠抽屉）

顶部遗物栏（`scripts/relic/relic_hud.gd`）是一个从左上角上边框下拉的紧凑抽屉：深色底仅30%不透明、细金色下边框，44像素遗物图标排成网格（悬停在抽屉下方显示遗物说明框），右端有书钉按钮（`assets/ui/pushpin.svg`）。按一局通常20～30件遗物设计：每行最多16件，超过后分成等长的多行（例如26件为两行各13件，约680×108像素），抽屉只占所需大小，始终留在画面左上角。收起时完全退到屏幕上方，只在上边缘留下「遗物 N ▾」小标签；没有遗物时整个抽屉与标签都不显示。

- 地图、战斗及其他界面（事件、宝箱等）：默认下拉并固定（书钉竖直、红色）。战斗中打开「解析」或「状态」窗口时视为收起类界面，抽屉自动收起以免遮挡窗口，关闭窗口后恢复固定。
- 商店、部队编制（地图编制、战斗中编制、强化／附魔选卡）：默认收起，书钉倾斜变灰。鼠标移到标签或抽屉上时下拉，移开约0.3秒后收回。
- 点击书钉或标签切换固定；每次切换到另一类界面时恢复该界面的默认状态。
- 收起时获得遗物（如在商店购买）会自动下拉约1.6秒，让飞入的遗物落在可见位置后再收回。

## 回合开始时的遗物释放

每个本方回合开始（包括开局第1回合），触发的遗物按获取顺序释放，并按效果分为三类（`RelicEffects.category`，依据遗物技能的基础效果编号）：

| 类别 | 判定 | 现有遗物 | 演出 |
| --- | --- | --- | --- |
| 攻击类 | 含效果1（攻击） | 郁金香2号、郁金香兵 | 照常逐个播放技能动画 |
| 支援类 | 含效果30～36（配置／排除支援） | 加奈美忍法帖、妖怪宝具、守护神、拉包尔之弓 | 一起配置 |
| 效果类 | 其他（护盾、异常、Boost、恢复、AP等） | 平实柠檬、赫尔曼石墙、塔罗柯发动机、3段喷射发动机、利萨斯的旗帜、赫尔曼的旗帜、男人的友情、医学全集、瓦古奖章、毒团子、低语的黑铠 | 一起释放 |

获取顺序中相邻的同类遗物合并为一批：整批在同一时刻按顺序结算，因此顺序依然有效——例如异常栏已满时，排在后面的遗物施加异常不会生效。整批的遗物图标同时闪光，新配置的支援同时出现（各自的出现音效），效果类只播放一次音效，整批约0.6秒。攻击类遗物会打断批次：例如顺序为「支援、支援、效果、攻击、效果」时，依次为一批支援、一批效果、攻击动画、再一批效果。
