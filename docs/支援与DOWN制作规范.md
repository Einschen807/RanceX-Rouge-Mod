# 支援、最大HP效果与DOWN

## 数据入口

支援定义放在 `data/supports.txt`；配置支援的主动技能和支援本身的效果技能都放在 `data/skills.txt`。卡牌继续通过技能ID引用，不增加人物脚本。三个文件均为UTF-8、`{ ... };`记录；描述中的 `r` 表示换行。

支援固定11字段：

```text
# ID, 名称, 识别名, 图标, 类别, 可解除, 持续回合, 效果技能ID, 重复规则, 下一级支援ID, 描述
{ 1, "支援攻击", "支援攻击", "魔法兵器", 2, 1, 3, 9201, 1, 0, "每个本方回合开始100%发动r物理攻击(1倍)" };
```

| 字段 | 填写规则 |
|---|---|
| ID | 唯一正整数，供技能效果30、31引用 |
| 名称 | 支援栏显示名 |
| 识别名 | 重复配置匹配键；同一升级链使用同一识别名 |
| 图标 | `assets/battle/support/`中的原版PNG名，省略扩展名 |
| 类别 | 原版分类：1地面、2普通、3特殊、4异界、5雷云、9强化；用于按类别解除，与图标/技能伤害类型分别填写 |
| 可解除 | 1普通解除技能可移除；0显示原版锁标记，普通解除不生效 |
| 持续回合 | 0永久；配置当回合计入持续时间，每次本方新回合开始减1，减至0先移除，再执行自动行动 |
| 效果技能ID | 引用自动行动2或被动行动3的技能；外部自定义事件2000～2999可读表，但需另接对应事件调度 |
| 重复规则 | 1替换并刷新时长；2忽略；3独立共存；4沿升级链提升一级并刷新时长 |
| 下一级支援ID | 升级目标；0为最高级，继续配置刷新最高级时长 |
| 描述 | 点击支援后的说明；空串使用效果技能描述 |

每方最多7个支援实例，满栏时新增失败，已有支援的刷新和升级仍可执行。剩余回合、施加者和实例ID属于战斗状态，不写入TXT。读表拒绝重复ID、缺失技能或图标、跨识别名升级和循环升级链；加载失败时整套卡牌/技能/支援数据库不投入运行。

支援攻击的AT来源自动取值：我方为部队综合AT，敌方为怪物基础AT。不填写来源AT比例，不借用配置者的部署AT。伤害仍乘本方战前物理/魔法加成、额外增伤及目标两层抗性；局内支援、异常不改部署AT和综合AT。

自动支援在本方回合开始发动，AP栏是发动概率，不消耗AP或领队主动次数。标准支援使用行动类型2；2000～2999仍保留原技能系统的外部事件编号，目前支援回合调度只触发类型2。

## 技能与支援联动

配置技能引用支援ID；支援再引用效果技能ID。例如：

```text
# 配置到己方支援栏
{ 9401, "己方支援攻击", 1, 6, "", "", 0, 30, 1, 0, 0, 0, 0, 0, "", 0, 1, "配置支援攻击" };
# 支援每个本方回合开始100%发动1倍物理攻击
{ 9201, "支援攻击效果", 2, 1, "", "", 100, 1, 100, 0, 0, 0, 0, 0, "", 0, 1, "物理攻击(1倍)" };
```

| 效果编号 | 数值含义 |
|---|---|
| 3 | 恢复本方最大HP的百分数；负数恢复对方最大HP的绝对百分数 |
| 4 | 失去本方最大HP的百分数；负数令对方失去最大HP的绝对百分数 |
| 5 | 本方领队DOWN，目标编码见下文 |
| 6、7 | 额外物理/魔法抗性百分数；支持负值，内部加算 |
| 8、9 | 额外物理/魔法增伤百分数；支持负值，与其他额外增伤加算 |
| 10～23 | 已有14种异常，编码不变 |
| 24 | 纯净；1～9给对方对应层数，11～19给自身个位数层数 |
| 25～29 | 预留异常拓展，不接受现有技能配置 |
| 30、31 | 在本方/对方配置数值指定的支援ID |
| 32 | 随机解除对方可解除支援的数量 |
| 33 | 随机解除对方一个可解除的指定类别支援 |
| 34 | 解除对方一个可解除的指定支援ID实例 |
| 40 | 被动军师增伤百分数；同方取最高，双方数值相减抵消 |
| 41 | 被动无敌结界，数值1启用 |
| 42 | 被动自爆体质，本方每次成功行动使对方失去最大HP的指定百分数 |
| 43 | 被动攻击封锁，数值1启用，禁用对方近战/远程/魔法技能 |
| 35、36 | 保留原有本场AT增益/按AT倍率治疗能力；旧效果4、3的含义移至这里 |

效果6～9在被动支援中随支援存在而生效，支援解除或到期即失效；放在主动技能里时则提供本场持续的相应数值增益。效果40～43由持续支援读取，不是一次性施法命令。未分配37～39。所有内置技能TXT已同步迁移旧编号；支援ID、技能ID和卡牌引用不变。纯净实际规则见[异常效果制作规范](异常效果制作规范.md)。

`3,20`恢复本方最大HP的20%；`3,-20`恢复对方20%。`4,20`令本方失去最大HP的20%；`4,-20`令对方失去20%。实际治疗不超过最大HP，扣血不超过当前HP；反再生阻止治疗。百分比失去HP不经过攻击增伤/抗性公式，仍受无敌结界保护。

## 已制作的支援

| 支援ID | 效果与持续回合 |
|---|---|
| 1 | 支援攻击：100%自动发动1倍物理攻击，3回合 |
| 2 | 无敌结界：永久，普通解除无效 |
| 3 | 自爆体质：配置在我方，我方成功行动后敌方立即失去2%最大HP，永久 |
| 4 | 攻击封锁体质：禁用对方近战、远程、魔法技能，永久，可解除 |
| 10～15 | 军师1～6级：10/20/30/40/50/60%额外增伤，持续9/9/4/4/2/2回合 |
| 20～23 | 物理阵1～4级：20/40/80/100%物理额外增伤，持续5/4/3/2回合 |
| 30～33 | 魔法阵1～4级：20/40/80/100%魔法额外增伤，持续5/4/3/2回合 |
| 40～42 | 蓄力1～3级：100/200/300%物理额外增伤，持续2回合 |
| 50、51 | 物理/魔法额外抗性20%，3回合 |

军师、物理阵、魔法阵和蓄力使用原版等级及持续回合设计，重复配置提升一级。除无敌结界外，当前所有支援均可解除，不显示锁。阵法和蓄力的提升与异常增伤进入同一个额外增伤括号；两层抗性分别相乘，见[伤害计算公式](伤害计算公式.md)。

无敌结界阻止攻击、自伤、百分比失去HP、毒、诅咒和即死预告的HP扣除。只有识别名严格为“兰斯”或“健太郎”的角色命中攻击、且经过正常计算可造成正伤害时，才破除结界；破除这一击正常扣血。MISS、零伤害、按HP比例扣血和支援攻击都不能冒用配置者身份破除。复用原版结界防御/破坏动画与各自专用音效。

自爆体质按成功行动计数：6连击只触发一次，自动行动也触发；释放失败不触发，自爆自身不会递归触发下一次自爆。攻击MISS或被结界挡住仍是一次已成功执行的行动。对方有无敌结界时，自爆动画可以播放，HP扣除被阻止。

攻击封锁阻止主动和自动的近战、远程、魔法技能；准备、恢复、特殊技能仍可用。将支援4配置到敌方即可禁用玩家攻击；特殊解除技能可恢复攻击。

支援栏、图标、锁、回合徽标、附加/解除动画复用原版素材。栏内说明按原版采用19号常规黑体、白字、细黑描边，无额外加粗。悬停时采用原版RGB各加64的高亮；自动支援发动时整栏放大至2.5倍，放大完成后触发攻击特效，停留0.8秒后缩回，时长随战斗速度缩放。攻击沿用对应特效的原版音效；安装包缺少代码引用的“系统／战斗行动”文件，未添加替代提示音。点击显示原版金边说明框、原版字体样式并压暗全屏；点击任意位置或右键返回，不增加悬浮说明。信息阻断期间隐藏该方支援信息，保留实际状态。

## DOWN目标与替换

| 效果5的数值 | 目标 |
|---|---|
| 1～7 | 本方随机DOWN指定数量的在场、未DOWN领队；不足则全部，目标不重复 |
| 11～17 | 从左到右第1～7领队，空位无效 |
| 21、22 | 施法者所在位置的左/右相邻领队；空位、边界无效，不跳过空位或循环 |

相邻目标采用技能准备时记录的释放者位置。敌方怪物只有第1领队：1～7和11可DOWN自身，12～17、21、22均无目标，尤其BOSS左右DOWN不会错误DOWN自己。

DOWN复用原版完整红色卡牌覆盖动画，含倒地人物和“Down!”字样，优先于行动结束标识；本回合留在原位置，全部主动和自动技能禁用，部署AT与阵营贡献不因DOWN改变。

下一回合开始，DOWN领队尝试自动退场，无需等待手动换人窗口。从同阵营已持有后备卡中选择星级最高的一张（同星按卡牌表顺序），排除在场卡、DOWN卡和本场已禁用角色的所有不同版本。没有可用候选卡时，原领队持续留在原位置并保持DOWN，后续回合继续尝试替补；同识别名的其他版本不属于可用候选卡。新领队本轮可以正常行动，也执行回合开始自动技能；原领队的技能使用记录保留。替换后按当前领队重算部队最大HP，当前HP最多截到新上限，不产生治疗。普通手动换人窗口及新领队本轮行动结束规则保持。

战斗结束、离开或重开时清除DOWN与退场角色记录。全部领队DOWN时不自动判负，支援与结束回合入口继续工作。

替补在新回合标题后按位置依次从下方上移、放大展示、缩小淡出，全部登场后才开始自动行动。右上角重开读取战斗开始前的完整快照，恢复原领队配置；机制及未来节点入口存档接口见[自动存档与战斗重开](自动存档与战斗重开.md)。

## 手动测试

DOWN立即禁用同识别名的所有版本。战斗中主动替换或移除领队，也会立即禁用已经上场后退场的角色身份，当前换人界面内就不能选回；未上场的后备卡不受影响。同识别名直接互换领队属于例外，不禁用该身份，但新上场的版本本回合行动结束；即使在同一换人界面换回原卡也保持行动结束。下一回合正常恢复行动。自动DOWN替补发生于新回合，其行动不被手动换人规则消耗。

禁用的后备卡使用原版“无法选择”素材和暗色遮罩，鼠标悬停仍有高亮；实际点击、键盘确认和拖动不会选择或上传该卡。仍在场的DOWN领队保留DOWN显示，可以被玩家主动替换或移除。战斗结束及战斗重开清除本场禁用记录；战斗准备时编制不触发这些限制。DOWN图标保持在卡牌本身的绘制顺序内，双方攻击等战斗特效显示在它上方。

在“百科大全 → 卡牌”部署测试卡；反引号打开控制台，输入 `battle 支援测试BOSS`。这个BOSS有20000HP、20AT、物理/魔法抗性0，第1敌方回合尝试左右DOWN且继续攻击，方便确认单人例外。

| 卡牌 | 上/下技能 |
|---|---|
| 支援测试01 | 配置我方/敌方支援攻击 |
| 支援测试02 | 配置敌方/我方无敌结界 |
| 支援测试03 | 配置我方自爆体质/敌方攻击封锁体质（封锁我方攻击） |
| 支援测试04 | 配置我方/敌方军师；重复使用逐级升级 |
| 支援测试05 | 配置我方物理阵/魔法阵 |
| 支援测试06 | 配置我方蓄力/解除敌方最多7个可解除支援 |
| 支援测试07 | 配置我方物理/魔法抗性20% |
| HP测试01 | 恢复我方/敌方20%最大HP |
| HP测试02 | 我方/敌方失去20%最大HP |
| DOWN测试01～03 | 随机DOWN数量依次1/2、3/4、5/6 |
| DOWN测试04 | 随机DOWN7名/第1领队DOWN |
| DOWN测试05～07 | 第2/3、第4/5、第6/7领队DOWN |
| DOWN测试08 | 左/右邻领队DOWN |

也可输入 `battle 结界测试BOSS`、`battle 攻击封锁测试BOSS`、`battle 支援攻击测试BOSS`，分别由敌人第1回合配置对应支援。结界测试请带原卡“Lv42 兰斯”（识别名兰斯）；“支援测试01”只是复用兰斯卡面，识别名是测试卡名，不具有破除结界的身份。

测试技能初始0AP，仍遵循每人每轮一次主动行动及原有连续使用AP+1规则。测试卡分别属于多个阵营，便于组合部署；同阵营不能同时占两个领队位。它们通过普通TXT读表出现在百科，不向真实存档发卡。修改TXT后使用项目外“一键编译并运行.bat”重新生成EXE。
