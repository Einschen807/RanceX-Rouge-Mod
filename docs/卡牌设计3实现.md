# 卡牌设计3

根据《卡牌设计3.txt》增加12组普通／强化版，共24张；完整卡库现为53组、106张。技能ID使用20300～20347中的对应槽位，沙袋被动为20350、支援ID为81。复用原卡面、身份、属性和性别，不修改原素材或导入设置。

## 确认与实现口径

- 用户最终确认所有新增特殊效果均使用技能ID自定义接口，包括巴顿护盾增伤；不新增编号基础效果。已有伤害、连击、护盾、DOWN、支援、强化、多属性等基础效果继续复用。
- 贝泽爱大普通及强化版的“跟我上”均强化3名；贝泽爱小均强化2名。
- 巴顿每满5%当前护盾，基础攻击倍率增加0.5／0.7，10%护盾时分别为4／4.9倍。坚如磐石使当前及之后获得的护盾在本场不自然消失，仍正常抵挡伤害。
- 沙袋为永续带锁支援，物理抗性20%；重复配置不新增实例。一般驱散不能解除，日光的主动清空友方所有支援包括带锁支援。
- 三色光线在伤害后分别施加燃烧、冰冻、触电，纯净仍逐项阻挡；升级魔法攻击拥有五种元素。
- 毘沙门天的加护从之后的我方回合开始，对七格中的正中间（第4格）领队施加BOOST。读取当时领队，空位或不可用领队不生效；重复施放不叠加。
- 重整旗鼓立即DOWN相邻左右领队，在下个我方回合开始、旧护盾自然结算后恢复1AP，强化版再加5%护盾。即使施放者下场，已预约效果仍执行一次。
- 舞女分别从第5／3轮开始可用。居合斩要求敌方至少一种异常。空蝉残月先清空友方所有支援，再按数量增加基础倍率并攻击。
- 雅典娜记录本场最近完成的友方技能，跨回合保留，敌方行动不覆盖。以雅典娜自身AT、属性和领队位置重新解析被模仿技能的效果，沿用被模仿技能的物理／魔法类型；只扣模仿技能自身AP和使用次数，不重复扣原技能费用或原施放者次数。没有历史时为空效果。重开／新战斗清空历史，预览使用独立副本。
- 岩石体质仅在领队有效配置时提供物理抗性，DOWN或下场立即失效。
- 普通AP、跨战斗AP累计（类型2）、本场AP累计（类型3）沿用现有运行规则；“本局内限制1次”使用类型4，换层或重置卡牌状态恢复；未写“本局内”的“限制1次”使用本场类型5。
- 稀有度0表示事件专用卡，百科可查看、显式发卡可获取，宝箱和随机商店不抽取。两张圣女的基础HP／AT暂按神魔普通档75／75处理；其他卡沿用稀有度统一数值规则。

## 额外抗性

物理与魔法分别计算，友敌双方一致：`额外抗性 = min(所有有效额外抗性之和, 最高单项正抗性)`。没有正抗性时上限为0，负数可正常增加承伤。领队被动、支援和直接抗性效果一并计算；基础部队抗性仍使用独立乘区。

示例：10+10+20→20；20+20+20−50→10；20×4−50→20；40+40−50→30。最高单项取当前有效来源；领队下场或支援移除后重新计算。

## 标题动画与验证

标题入场动画播放速度为1.5倍；入场音效保持原速、原音调，仍由动画第30帧触发，自然进入标题后允许音效播放完毕。手动跳过入场时停止音效。进入待机后动画恢复1倍，背景音乐速度保持原样。
