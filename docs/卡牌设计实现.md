# 卡牌设计实现

本页记录第一批《卡牌设计.txt》的32组卡牌，共64张、114项配套技能，包含赛斯魔法兵器的自动攻击和能力反击。后续《卡牌设计2.txt》新增9组，当前合计41组、82张，详见[卡牌设计2实现](卡牌设计2实现.md)。旧卡牌与测试卡牌定义不重新加入。百科、商店和奖励卡池自动跟随卡牌库；原版卡面素材与共用技能、支援和怪物配置保留供后续使用。

卡面、识别名、阵营、属性、性别逐项核对原版 `Rance10EX.txt`。稀有度按设计文件，其他阵营基础HP与AT按稀有度1/2/3对应50/75/100，神魔阵营为75/100/125；强化卡名、技能名均追加半角 `+`。不从卡名等级推导AT。说明中的作者注解不写入游戏，支援名称方括号保留。

## 已确认的规则

- 未写AP累计的技能沿用既有普通AP规则：连续回合使用暂时+1AP，间隔恢复。“AP累计”使用类型2，跨战斗保留；“本局内AP累计”使用类型3，只在当前战斗累计，下一场恢复基础费用。一次限制仍按对应的类型4／5处理。
- 强化描述省略“限制1次”时，保留原限制并在实际说明中补齐，涉及艾蕾诺亚、阿玛德斯、伊安和矮人。
- 伊安为稀有度2。洛基强化版每逢3的倍数回合自动获得7%护盾，基础版4%。
- 协同防御算法的“格挡”按现有护盾处理，原版与强化版均为本局内限制1次，使用AP类型4，沿用本局次数的换层重置规则。
- 赛斯魔法兵器独立共存，持续2回合，按既有规则计入配置当回合；新回合先减时长，到0移除，再执行自动技能。其攻击使用综合AT、魔法类型、无属性，不继承召唤者的炎属性。
- 双重咏唱仅对本回合内友方下1个（强化版2个）领队主动技能各额外释放1次；结束玩家回合即清空未用次数。排除自身、自动、支援和遗物行动，保留每场限制1次。
- 女王号令对利萨斯领队的主动与自动技能生效；被动不属于施放，支援与遗物不属于领队。
- 额外施放不另扣AP、不消耗技能使用次数、不占新的主动行动，不再触发额外施放。女王与双重咏唱的额外次数相加。技能自身的效果继续结算，包括配置支援、贝壳扣除和能力叠加；倍率按额外施放时的COMBO、贝壳及已生效能力重新计算。

## 能力与被动

突击号令每次使带“突击”的技能基础倍率增加0.5；女王号令每次增加一次额外施放；协同防御算法按成功生成的新支援授予护盾，支援升级或满栏失败不计生成。招架反击由联合部队持有，受到敌方攻击并实际损失HP且仍存活时，按综合AT反击；护盾完全吸收、自爆、异常和直接HP损失不会触发。

能力数据保存在 `BattleState.ability_rules`，领队退场后继续有效；状态面板显示叠加后的合计数值和发动次数。新战斗清空，重开恢复战前快照。普通被动按当前在场且可用的领队实时读取，退场或DOWN后失效，不写入部队永久加成。

军师效果复用既有军师升级链。`[军师效果]++`从空栏连续配置两次，得到二级军师，占用一个支援位置，不生成两个独立军师。

贪婪之手只有本技能的倍率伤害完成斩杀时才记录额外贝壳，合并到胜利搜刮的贝壳奖励；预览、非斩杀、自爆补刀和重复结算不会重复登记。重金打击先按扣款前贝壳计算倍率，再扣至最低0。

## 新增编号基础效果

| 编号 | 功能 | 数值 |
| --- | --- | --- |
| 45 | 清除本方异常 | 正整数N，随机清除最多N种异常，保留纯净 |
| 46 | 当前HP比例恢复／损失 | 下述比例参数编码 |
| 47 | 已损失HP比例恢复／损失 | 下述比例参数编码 |
| 48 | 技能附加属性 | 0无、1炎、2冰、3雷、4光、5暗；按数字去重、顺序无关 |
| 49 | 随机DOWN替身优先 | 被动，数值1启用；不影响指定或相邻位置DOWN |
| 50 | 使目标HP归零 | 数值1，对方目标；社会性抹杀另以条件限制普通怪 |

46、47使用符号选择目标：非负为自己，负数为对方。绝对值 `0～100` 表示恢复相应比例；`1000+比例` 表示失去相应比例。例：`46,-1005`为对方失去当前HP的5%；`47,50`为恢复自己已损失HP的50%。损失仍沿用现有直接HP损失的防护结算，恢复受反再生限制。最大HP恢复／损失继续使用3、4。

48与卡牌自身属性取并集，重复数字不重复加成。`12`与`21`均为炎冰双属性，`12345`与`23541`均为全属性。燃烧、冰冻、触电对应的增伤按现有额外增伤乘区加算，可在同一次多属性命中同时生效；0不抹除卡牌已有属性。

49存在多名有效领队时在优先者中随机选人，仍不足时再选其他领队。50是通用归零命令；社会性抹杀通过新增条件 `敌方普通怪` 禁止对精英、BOSS施放，失败不扣AP或使用次数。

## 代码与数据

卡牌与技能仍分别定义在 `data/cards.txt`、`data/skills.txt`，支援位于 `data/supports.txt`。Lv42兰斯保留技能ID20、21，强化版使用22、23；其余设计卡使用20004～20127，20200为魔法兵器攻击，20210为能力反击。

`scripts/skill/designed_skill_effects.gd`按稳定技能ID实现特殊命令；`skill_elements.gd`解析属性数字；`scripts/battle/battle_abilities.gd`调度全局能力与额外施放；`battle_leader_passives.gd`读取在场被动。HP、护盾、异常、支援与DOWN继续由共用战斗消费者结算。

预览深拷贝能力、额外施放队列、贝壳与行动封锁，实际与预测共用效果解析。战斗结束的额外贝壳只进入真实搜刮界面。新快照字段均可选，旧快照缺少时使用空能力和零奖励；新增字段在恢复前完整校验。

卡牌详情保持原版面板尺寸，长说明正确换行；战斗AT的两种操作模式共用原版26像素宽白渐变数字，完整卡面模式保留底部攻击力栏。点击后的技能详情不显示技能名、无红色全卡悬停框，AP栏位于上方，描述区一次完整显示至多四行，不使用滚动条。上下按钮留出间隔，图标保留上边距；AP及描述框取自原版纹理，悬停使用原版青绿色循环闪烁动画。连续浏览复用普通/详情视图；真实战斗状态变化时使缓存失效。不增加悬浮说明。

战斗LOG通过 `scripts/battle/battle_skill_log.gd` 从当次解析的命令读取技能倍率，技能名后显示如“重金打击（3倍）”“魔力球（0.1倍×5连击）”。女王、突击、反击、协同防御等能力发动时显示叠加后的合计数值；额外施放重新计算并记录当次倍率，不重复记作自动技能。这里的倍率为技能基础倍率，COMBO通用增伤、抗性等仍反映在实际伤害记录中。

所有生成脚本、原版数据核对、数值与回归检查、64张卡的截图、战斗演出截图及日志统一保存在工程外 `test/card_design_20261016/`。
