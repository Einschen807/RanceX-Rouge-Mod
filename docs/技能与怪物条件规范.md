# 技能与怪物条件规范

`data/skills.txt` 的发动条件与 `data/monster_behaviors.txt` 的行为条件共用 `BattleConditions`。条件填写在双引号内；空字符串或 `ALWAYS` 表示始终满足。条件只判定战斗状态，不执行效果。

友方固定指玩家方，敌方固定指怪物方，不随技能使用者改变。AP、COMBO均读取玩家当前数值；主动技能在扣除费用前检查AP条件。条件符合后，技能仍需满足通常的AP费用、行动次数、状态封锁和使用次数规则。自动技能还需通过自身概率。被动支援只在自身技能条件满足时提供持续效果。

## 条件写法

表中的X替换为非负整数；HP允许小数，范围0～100，表示最大HP的百分比。以上、以下都包含X本身。

| 写法 | 判定 | 示例 |
| --- | --- | --- |
| `COMBOX` | COMBO恰好为X | `COMBO10`仅10满足，9、11都不满足；`COMBO0`必须无COMBO |
| `COMBOX以上` / `COMBOX以下` | COMBO大于等于 / 小于等于X | `COMBO5以上`对应5～13；`COMBO2以下`对应0、1、2 |
| `APX` / `APX以上` / `APX以下` | 玩家当前AP恰好为 / 大于等于 / 小于等于X | `AP3`、`AP2以上`、`AP1以下` |
| `友方支援X` / `敌方支援X` | 指定一方支援实例数恰好为X | `友方支援0`要求玩家支援栏为空 |
| `友方支援X以上` / `友方支援X以下` | 玩家支援实例数大于等于 / 小于等于X | `友方支援2以上`至少2个；敌方同理 |
| `友方异常X` / `敌方异常X` | 指定一方异常种类数恰好为X | `敌方异常1`只允许存在一种异常 |
| `友方异常X以上` / `友方异常X以下` | 玩家异常种类数大于等于 / 小于等于X | `友方异常2以下`允许0、1、2种；敌方同理 |
| `友方异常存在<异常名>` / `敌方异常存在<异常名>` | 指定一方存在该异常 | `敌方异常存在<燃烧>` |
| `友方支援存在[支援名]` / `敌方支援存在[支援名]` | 指定一方存在该支援 | `敌方支援存在[无敌结界]` |
| `友方HPX以上` / `友方HPX以下` | 玩家剩余HP百分比大于等于 / 小于等于X | `友方HP50以上`包含恰好50%；敌方同理 |
| `回合数X` | 当前回合恰好为X | `回合数1`仅第1回合 |
| `回合数X以上` / `回合数X以下` | 当前回合大于等于 / 小于等于X | `回合数3以上`从第3回合起 |
| `回合数X倍数` | 当前回合为X的整数倍，X必须大于0 | `回合数3倍数`对应3、6、9…… |
| `敌方普通怪` | 敌方怪物类型为普通怪（1） | 社会性抹杀只对普通怪发动，精英与BOSS不满足 |

支援数量按实际占用的实例计数：同名支援若可叠加，每个实例各算一个；永续、带锁和斗神强制追加的支援也计入。异常数量按有效异常种类计数，重复附加同一种异常只增加持续回合或层数，仍算一种。纯净属于异常栏的一种状态，也计入；剩余回合或层数为0的状态不计入。

支援存在条件按显示名称匹配，同时兼容识别名，不是支援数量或技能编号。异常名使用当前异常表的准确名称，未知异常名会被拒绝。空的 `[]` / `<>` 不允许。HP按真实剩余值与最大值计算，不读取界面四舍五入后的数字；`友方HP50%以上`也可作为百分号写法。

## 组合与括号

`&&` 表示与，所有条件都需成立；`|` 表示或，至少一个条件成立。`()`先判定括号内部，将结果视为整体；无括号时先判定`&&`，再判定`|`。可以嵌套括号，条件间允许空格。

```text
"AP2以上 && (敌方异常存在<燃烧> | 友方支援存在[无敌结界])"
"COMBO0 && 友方支援2以下 && 敌方HP50以下"
"(回合数3倍数 | 回合数1) && 敌方支援存在[无敌结界]"
```

第一例要求AP至少2，且敌方燃烧或友方无敌结界至少满足一个。技能和行为可直接使用完全相同的表达式。

技能主动/自动发动时读取当时的战斗状态；被动支援读取效果时检查条件。怪物仍在每回合开始时按数据顺序选择第一个满足条件的行为，随后逐个检查各技能自己的发动条件，失败只跳过该技能。开局追加沿用既定强制释放规则，不检查技能条件。

## 旧写法兼容

旧的 `ROUND>=3`、`ROUND%3==0`、`COMBO>=5`、`COMBO0`、`HP<50%`、`PLAYER_HP<=100`、`存在支援[锁定目标]`以及单个`&`继续可用，并可与新写法混合。旧`HP`和`存在支援[...]`仍指技能使用者自身一方；旧HP不带百分号时为实际HP。新内容使用明确的友方/敌方前缀，避免相对方位混淆。

括号不配对、缺少条件、连续错误操作符（如`|||`或`&&&`）、零倍数、未知词及非法数值会在数据加载时被拒绝，不会部分执行。
