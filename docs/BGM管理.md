# BGM 管理

## 现状

全局只有一个 BGM 播放器：自动加载场景 `BGM`（`scripts/audio/bgm_manager.gd`，Music 总线）。目前标题画面（`系统／回合ＳＴＡＲＴ`）与失败界面在代码中直接请求曲目，其他场景尚未接入。

## 曲目登记表 `data/bgm.txt`

已登记原版 Rance10 的全部 76 首 BGM（来源：原版 `Rance10Sound.afa` 中 `timemap_sound.ex` 的 Group 1 曲目），**尚未接入游戏，音频也尚未导入工程**。

格式：`{曲目名,原版曲名,分类,循环起点,循环终点,说明};`

| 字段 | 内容 |
| --- | --- |
| 曲目名 | 原版音频包中的文件名（不含 `.ogg`），今后地图、怪物、事件、控制台都用它引用曲目 |
| 原版曲名 | 原版 Rance10EX「BGM信息」中的标题（`ＡＤＶ／爱丽丝主题`、`系统／战斗成果` 原版未登记，留空） |
| 分类 | 片头片尾、剧情、系统、地图、战斗 |
| 循环起点／循环终点 | 原版 LoopBeginSample／LoopEndSample 采样位置；标题音乐沿用的 541227 即来自此表 |
| 说明 | 用途备注，可自由修改 |

分类数量：片头片尾6、剧情22、系统11、地图27、战斗10。原版普通怪物战斗曲为 `战斗／怪物`（Zako Battle）。

## 已确定的接入方案（待实装）

- 音频从原版音频包原样导出到 `assets/bgm/`，不重新编码；循环点按上表换算。
- 播放优先级：事件指令／控制台 `bgm 曲目名` ＞ 单个怪物或事件指定的曲目 ＞ 地图层数与地图主题的默认曲 ＞ 场景类型默认曲（标题、地图、普通战斗、精英、BOSS、商店、休息点、事件、失败）。
- 地图音乐按层与地图主题区分。
- 每个怪物可单独指定战斗曲（`monsters.txt` 增加可选字段），留空时使用默认战斗曲；大部分怪物使用同一首。
- 播放器：切换时淡出淡入；从战斗、商店、事件返回地图时续播原位置；同一曲目重复请求不重播；胜利等短乐句播完后恢复原曲；控制台 `bgm` 命令接入补全。

原始解包数据与登记表生成过程位于工程外 `test/bgm_registry_20261030/`。
