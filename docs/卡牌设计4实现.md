# 卡牌设计4

按《卡牌设计4.txt》制作27组普通／强化卡牌：新增26组52条记录，为既有Lv45赫尔曼骑士的两个版本补齐二技能。卡库现为79组158张，全部本批卡牌稀有度1、基础HP／AT为50。卡面、识别名、属性与性别沿用原版记录；原图和导入设置不变。

## 编制效果

用户确认采用可复用编号基础效果。51＝HP增加率，52＝物理增伤率，53＝魔法增伤率，54＝物理抗性；数值为非负整数百分点。只能配置在无条件被动技能的三个效果槽中，描述文字不参与结算。

第一回合首发某阵营的任意可用领队，即激活所有持有的同阵营卡牌上的编制效果，包括未上场的卡牌。各卡加成相加，普通版+1%、强化版+2%；升级替换原卡，不同时计入两个版本。开战时锁定本场加成，之后换人、DOWN、离场或临时改变卡牌版本均不重新计算。后续换入未首发阵营不能激活其编制效果。

准备阶段、地图与编制页按当前阵容预览；真正开战前记录最终首发阵容。HP计入本场最大HP，并保留入场缺失HP；物理／魔法增伤计入部队基础增伤，物理抗性计入部队基础抗性，与额外抗性分开。均沿用部队加成上限及上限解除规则。预测复制独立快照，重开重新读取准备阵容，战斗结束清除临时快照，不写入周目存档。

编号注册位于 `scripts/skill/skill_base_effects.gd`，持续读取位于 `scripts/skill/skill_formation_effects.gd`，技能ID为20400～20407。普通被动与自动行动统一使用 `skill_7.png`；部队编制效果使用原 `skill_8.png`，由效果编号判断，不解析描述。

## 主动技能

- 亲卫队远程攻击、利萨斯赤／蓝／白兵突击：普通1AP、强化0AP，倍率均为1倍。
- 五种赫尔曼骑士共用既有防御突击：普通1AP／1倍／5%护盾，强化1AP／1.5倍／8%护盾。Lv45二技能为魔法增伤；Lv35、Lv40为HP增加；Lv30、Lv33为物理抗性。
- 赛斯男性魔法2AP／2倍，女性1AP／1倍。炎、冰、雷普通版分别施加2层／1层对应异常，强化增加1层。光、暗没有异常，用户确认强化倍率分别提高至3倍／1.5倍，AP不变。
- 自由都市警卫兵突击(弱)：普通0AP／0.5倍，强化0AP／1倍。

新增主动技能使用20410～20415、20420～20439，复用现有伤害、护盾与异常基础效果。所有普通AP技能沿用现有连续回合费用规则。
