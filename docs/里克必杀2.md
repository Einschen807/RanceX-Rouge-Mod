# 里克必杀2：赤色死神

独立登记资源：`assets/cut_ins/里克必杀2.tscn`，技能TXT第6栏可填写 `"里克必杀2"` 选用。当前技能表已选用里克必杀2，本轮保留用户的选择，未改技能配置。原里克必杀1、谦信必杀2及共用脚本、导入设置保留。

独立脚本：`scripts/skill/里克/rick_crimson_reaper_cut_in.gd`，继承既有曲面长条的编舞，仅覆盖里克的取景、配色与背景绘制。卡牌、语音和立绘均来自里克自己的素材；独立预览也使用Lv58里克的完整卡面。

- 深红、酒红、近黑与冷白构成主色；边框为淡红银色，右侧采用里克独立的五层“赤”字图案，区别于谦信的神圣双环和毘字。
- bar先从细线沿弧形轮廓向上下张开，中央略窄，两端略宽，0.50秒完全展开，无果冻回弹。
- 里克红甲头部特写从右快速进入左侧，再持续缓慢左移；右肩自然渐隐，为右侧图案留出空间。
- 中央卡牌以0.24秒快速平移到位，不旋转；bar中央高422，卡牌高360。
- 中心“赤”字由七组手绘多边形笔画构成，横画和撇捺收尖，保留少量干笔缺口；浅血红字形保持稳定，不依赖额外字体或插画。
- 字后为近黑至深酒红的暗腔和低透明度雾气，帽檐下藏两块斜眼窝阴影，0.72秒附近有一次微弱暗红闪光，避免画成明确的骷髅脸。
- 内圈仅保留三段很淡的断续细弧和六处小刻纹，逆时针每秒0.48弧度，约为谦信内圈的2.18倍。
- 外形为偏窄、偏高的尖顶兜帽；帽檐向下扣，两侧向内包裹。外缘暗红、内沿亮红、开口边缘近黑，使用大块平涂体现厚度。兜帽布料和压低的帽檐绘制在“赤”字之后，处于文字上层；暗腔和眼窝则在文字后方。
- 下摆为三条不对称、长短不同的破布飘带，中间最长，边缘有少量撕裂缺口，分别以不同相位缓慢飘动。兜帽本体仅有轻微呼吸，文字不随之伸缩。
- 外围仅保留四处低透明度烟雾和四点细小余烬，不增加密集装饰。所有层共享展开淡入进度，约0.48秒随bar接近完全展开完成淡入。
- 1.10秒起手结束，首个原攻击特效创建时，卡牌、立绘、五层赤字图案和bar一起冻结并碎裂。命中帧、AP、伤害和技能使用次数继续由原战斗逻辑管理。
