# 领队强化、必杀、连击

基础效果42＝强化（BOOST），43＝必杀，44＝连击。三种状态按卡牌分别记录，可同时存在；重复附加同一种状态不会叠加倍率或段数。本方回合结束时清除，换下或DOWN时移除，不继承给替补。

| 数值 | 目标（释放者所在方） |
|---|---|
| 1～7 | 随机对应数量的不同在场且未行动结束的领队，合格对象不足时取全部 |
| 11～17 | 从左至右第1～7个领队位置 |
| 21 / 22 | 释放者左 / 右紧邻位置 |

例如 `42,3` 强化随机三名领队；`43,13` 给予第三位置领队必杀；`44,21` 给予左邻领队连击。空位、DOWN、越界无效，不跳过空位查找下一名。敌方怪物视作一个领队，仅随机数值与11有有效目标。

随机强化、必杀、连击先排除空位、不可用／DOWN和已行动结束的对象，再抽取目标，不让已行动对象占用名额。主动释放者在选取时已登记行动结束，因此也会被排除；自动技能没有消耗主动行动资格，不因此被排除。固定位置和相邻选取沿用原有规则。DOWN的随机、固定和相邻选取均允许已行动结束对象，但已DOWN对象不能重复施加。

三种状态仅作用于近战、远程、魔法攻击。强化给每段攻击的额外增伤率加50个百分点；必杀给本回合首次攻击的第一段加100个百分点，随后消耗。MISS、结界或抵挡也消耗该段必杀，恢复、准备、特殊与支援攻击不消耗。强化、必杀与每点Combo的10个百分点在现有额外增伤率内加算，再与基础伤害、基础抗性、额外抗性乘算；零Combo时强化与必杀同时存在且无其他修正，第一段为2.5倍，命中产生1Combo后第二段为1.6倍。

连击仅为原本单段的攻击追加一段相同攻击；原有2段以上不追加。其他效果仍只执行一次，额外攻击独立判定命中、抵挡和护盾，并按现有连击动画节奏结算。必杀可强化原有多段攻击的第一段。

悬停预测使用实际规则的独立副本，逐段累积Combo，不改变实际Combo、消耗实际必杀或推进实际随机状态。重开还原准备阶段记录。原版FLAT时间轴和贴图位于 `assets/battle/native/leader_*`，保持原版文字跳动、金色边框与流动彩光；多个文字按必杀、BOOST、连击排列。循环光效按原来的三分之一速度播放，修改后三倍速等于修改前一倍速，文字跳动保持原有速度；切换倍速、刷新与抬升均保留光效速率。技能按钮刷新与卡牌抬升不会重启动画。已行动卡牌优先显示行动结束样式，避免文字遮盖；抬升的行动卡牌仍显示其状态。
