# 护盾与自定义技能

新增效果前必须先询问用户：采用可复用的基础效果编号，还是按技能ID实现的自定义接口。只在用户确认后分配通用编号。

## 通用护盾

任意效果槽填写 `40,5` 给玩家5%最大HP的护盾；`41,5` 给怪物5%最大HP的护盾。目标固定，不根据施法方翻转。护盾不属于支援实例、不占支援栏，不改变HP或最大HP。重复获取叠加，5%加10%得到15%，总量上限999%。获取时按目标当前最大HP换算为实际临时HP，受到伤害后按当前最大HP计算剩余百分比。

默认在目标方下一次回合开始时消失，先清理护盾再处理回合开始异常与自动技能。玩家护盾可以抵挡接下来的敌方回合，怪物护盾同理。攻击先计算增伤、抗性、命中与结界/一次抵挡，再消耗护盾，只有溢出部分扣真实HP；百分比扣HP与异常伤害也先消耗护盾。MISS不消耗护盾。连击逐击消耗，治疗只恢复真实HP。

`BattleShields.add(state, side, percent, options)` 提供扩展接口，`side` 为 `player` 或 `enemy`：

| 参数 | 默认 | 含义 |
|---|---|---|
| `duration_turns` | 1 | 每经过指定次数的目标方回合开始进行一次衰减；0永久 |
| `decay_percent` | -1 | -1到期清空；非负值每次减少对应最大HP百分数，例如5减少5个百分点 |
| `prevent_decay` | false | 方级策略开关，停止自然衰减及计时，不影响受到伤害时消耗 |

单次授予可用 `options` 指定持续回合数与衰减值；默认值和停止衰减开关通过 `state.shield_policy[side]` 配置，供未来遗物、体质调用。每次授予独立计时，受击优先消耗最早到期的护盾。悬停预测深拷贝护盾与策略，不改变实际状态；战前快照保存这些字段，旧快照使用默认空护盾。

敌方血条左端、玩家血条右端覆盖不透明暖银灰盾形标志及剩余百分数，数字向上取整避免有护盾时显示0；血条保留原版边框，不附加白色描边；盾牌绘制在护盾遮罩上方，数字沿用原版HP数字字体。不透明暖银灰遮罩以原版表面明暗作金属质感，完全覆盖血条原色，遮罩长度为 `min(护盾百分比,100%)`。超过100%仅数字继续增长。信息阻断隐藏护盾数值及覆盖层。悬停攻击时，如果护盾仍剩余就闪烁护盾；若预期击碎护盾，则暂时隐藏护盾，仅闪烁真实HP损失部分。离开悬停即恢复，不实际消耗护盾。

## 护盾动画

护盾标志首次出现时从上方32像素下落至原位，同时淡入；数字随标志一起移动。护盾遮罩长度平滑增长或收缩，连续叠加及受击时从当前显示长度继续过渡。超过100%仍只覆盖整条血条，数字显示完整护盾百分数。

受击清空护盾时，标志及其数字沿中间凹凸不规则的折线裂口撕成左右两瓣，向两侧分开16像素、下落28像素、略微向外倾斜并淡出，护盾条同时收回。两瓣共享互补的裂口形状，保留原标志的金属材质、边缘和数字。自然清空时先播放完整的护盾条收回，再播放同样的碎裂动画；部分自然衰减只缩短护盾条，不碎裂。基础动画时间为登场0.28秒、护盾条0.30秒、碎裂0.42秒，均跟随战斗动画速度，包括播放过程中修改倍速。

`BattleState.shield_event(side, event)` 区分获取（`gain`）、受击（`damage`）和自然衰减（`decay`）。这只是表现通知，实际护盾值即时更新，不等待动画；悬停预测的独立状态不触发实际战斗动画。普通UI刷新不会重复启动动画。重新获取会取消正在退场的动画；信息阻断同时隐藏标志、护盾条和碎片，过期后解除阻断不会残留图像。攻击悬停闪烁等当前护盾和HP过渡结束后显示。

## 独立自定义规则

在 `data/skills.txt` 将“是否自定义”设为1，基础效果槽可全部为0。主动／自动的独立效果写在 `SkillCustomEffects.resolve(skill_id, context)`；支援引用的被动规则写在 `SkillCustomEffects.passive(skill_id)`。代码只引用技能ID，不从描述解析效果，不在TXT用新的基础编号引用特殊规则。

| 技能ID | 自定义规则 |
|---|---|
| 9202 | 无敌结界 |
| 9203 | 自爆体质，成功行动后令对方失去2%最大HP |
| 9204 | 攻击封锁 |
| 9210～9215 | 军师10／20／30／40／50／60%，同方取最高，双方抵消 |
| 9260 | 我方伤害抵挡，抵消一段命中攻击后移除支援 |

上述规则原来的40～44编号已迁出。40、41现用于护盾；42、43、44现用于领队强化、必杀、连击，规则见《领队强化必杀连击》。支援仍通过现有30、31配置，支援表引用原技能ID，无需新增编号。

## 护盾测试卡

双方护盾共用玩家护盾的银灰表面与配色，敌方作水平镜像；各自红/蓝HP纹理只决定遮罩轮廓。盾牌造型、边缘、数值字体保持一致，敌方左端、玩家右端。

在百科卡牌页面可以同时部署以下三张不同阵营的测试卡，默认基础HP40、AT10，初始技能0AP，每人每回合仍只能主动行动一次。

| 卡牌 | 阵营 | 上技能 | 下技能 |
|---|---|---|---|
| 护盾测试01 | 主人公 | 玩家护盾5%（9601） | 怪物护盾5%（9602） |
| 护盾测试02 | 利萨斯 | 玩家护盾10%（9603） | 怪物护盾10%（9604） |
| 护盾测试03 | 赫尔曼 | 玩家护盾30%（9605） | 怪物护盾30%（9606） |

先使用前两张的上技能可以观察玩家15%护盾；三张同一侧技能全部使用会叠加到45%。下技能给怪物护盾，可搭配其他攻击卡检查护盾受击与悬停预览。三张卡使用普通TXT记录自动进入百科，不加入初始卡组。
