# 必杀技演出（cut-in）

`data/skills.txt` 现在固定18个字段，第6个字段是必杀技演出的String名称，紧接特效名：

```text
# ID, 名称, 行动类型, 技能类型, 特效, 必杀技演出, AP/概率, 效果1, 数值1, 效果2, 数值2, 效果3, 数值3, 自定义, 条件, 大招, AP类型, 描述
{ 21, "兰斯重击", 1, 1, "", "兰斯必杀1", 3, 1, 300, 0, 0, 0, 0, 0, "", 1, 1, "攻击(3倍)" };
{ 20, "突击－零－", 1, 1, "", "", 0, 1, 100, 0, 0, 0, 0, 0, "", 0, 1, "攻击(1倍)" };
```

`"兰斯必杀1"` 对应 `res://assets/cut_ins/兰斯必杀1.tscn`；`"兰斯必杀1.tscn"` 也可使用。里克对应填写 `"里克必杀1"`。只填文件名，不填目录或Godot路径。空字符串 `""` 表示没有演出，也不会按技能类型或“大招”字段补默认演出。是否播放还受设置中的“必杀演出”三选开关控制。

## Godot场景制作

1. 创建以 `Control` 为根节点的场景，保存为 `assets/cut_ins/<名称>.tscn`。画布按项目1920×1080制作；运行时根节点会铺满战斗画面。
2. 在根节点下直接添加名为 `AnimationPlayer` 的节点，创建名为 `cut_in` 的动画。动画必须有正时长且关闭循环；无需设置自动播放，战斗会显式播放。
3. 人物特写、色块、速度线和文字可分别使用 `TextureRect`、`ColorRect`、`Label` 等节点，通过这个动画控制位置、透明度、缩放及可见性。演出相关纹理和音效也放在 `assets/cut_ins/` 内。
4. 可加入 `AudioStreamPlayer` 并使用动画音频轨道播放。演出语音统一走独立的 `Voice` 总线，由设置中的“语音音量”控制，音高保持原样。需要拖尾的音效应在动画结束前完成，因为演出结束会回收整个场景。

场景无需人物专用运行脚本。演出动画应由上述 `AnimationPlayer` 控制，其播放速度固定为1.0，不受战斗倍速或普通特效节奏影响。新场景的内部动画也应使用正常时间，避免自行乘战斗倍速。所有Control节点运行时不接收鼠标或键盘焦点，保留战斗现有输入及右键返回处理。

## 播放与容错

流程为卡牌上抬 → 必杀技演出 → 对应技能特效 → 命中帧数值结算 → 特效收尾。演出在卡牌和技能提示上方显示，结束后移除；只增加表现时间，不扣额外AP、不增加行动或伤害结算次数。

主动技能、成功入队的自动技能和可执行的敌方技能共用这一流程。被动技能没有独立释放过程，不播放演出；失败的自动触发和条件不满足的敌方行动不会进入演出。

名称不存在、场景根节点类型不正确、缺少指定动画或动画循环时，日志会提示并跳过演出，技能仍按原流程执行。不会使用其他角色演出作为默认值。

导出预设包含全部Godot资源，新场景及其引用资源会随项目打包。修改技能表或演出场景后，需重新导出才能更新嵌入EXE的内容。

## 现成的里克与兰斯演出

已提供 `assets/cut_ins/里克必杀1.tscn` 和 `assets/cut_ins/兰斯必杀1.tscn`。技能第6栏分别填写 `"里克必杀1"`、`"兰斯必杀1"` 即可调用。设置中的“不播放演出”跳过cut-in；“每次播放演出”播放所有已配置的演出；“仅致命一击时播放”仅当我方本次技能结算能击杀怪物时播放。致命判定复用实际结算，包括多段伤害、抗性、加成和条件；已触发的自动技能使用本次准备好的指令，不重复判概率。空演出名始终不播放。

两者共用 `scenes/cut_in_bar_template.tscn`：背景是紧贴战斗画面左上角的三角形，画面左边和上边构成两条边，只绘制一条从左下通往右上的斜边。默认顶点为逻辑坐标(0,0)、(1180,0)、(0,378)，斜边角度约18度；横向长度保持1180，左侧高度从270增加到378，即1.4倍，右端仍为尖角并带收束刻线。人物宽度由1050增至1470，即放大1.4倍，重新取景，让头肩贴近边缘。

背景速度线分成慢速细暗线、中速彩色线、快速粗亮线，分别约520–700、1100–1400、2200–2700逻辑像素/秒。底部深色区域带半透明渐变、颗粒和斜向纹理；立绘保持自身不透明度。入场时人物从左下冲入，轻微过冲后在0.28秒归位；两条白青色前景亮斩线在0.08–0.28秒间擦过，随后消失。结束时沿右上方向擦除，过渡期间背景仍贴住画面左边和上边。画面其余区域透明，人物与背景共用三角形裁切，立绘不会伸出框外。

里克使用红色调和提供的“拜拉威”语音；兰斯使用绿色调和提供的“别挡道杂鱼”语音。透明立绘由原参考图提取，原参考图及语音保留在项目外。纹理和MP3的运行副本位于 `assets/cut_ins/portraits/`、`assets/cut_ins/voices/`。

## 复用背景框

### 谦信必杀1

`assets/cut_ins/谦信必杀1.tscn` 使用用户“谦信必杀技素材”目录中的立绘及原始 OGG 语音，配蓝白色速度线。技能 TXT 第6栏填写 `"谦信必杀1"` 即可播放，不需要改变技能效果或大招栏位。运行副本位于 `portraits/kenshin.png` 和 `voices/kenshin.ogg`；源图保持原样，通过仅此场景开启的 `portrait_black_matte` 去除纯黑底色。入场、语音停留和退场沿用共享模板，声音走 Voice 总线，战斗倍速不改变演出节奏。


1. 在Godot中从 `scenes/cut_in_bar_template.tscn` 创建继承场景，保存为 `assets/cut_ins/<新演出名>.tscn`。也可以复制现有角色场景并更换根节点参数。
2. 根节点的 `portrait` 填透明立绘，`voice` 填语音资源；这两个参数是必需的角色素材。`accent` 可改背景及速度线颜色。
3. `portrait_position` 调整立绘位置，`portrait_width` 调整取景大小。高度自动按原图比例计算，避免人物拉伸；参考1920×1080画布调整头部在人物条内的位置。
   `frame_extent` 的X值控制三角形在屏幕顶部的长度，Y值控制左侧高度；调整两者比例即可改变斜边角度，背景和人物裁切会一起更新。
4. 在技能TXT第6栏填新演出名。背景框、裁切、速度线及过渡沿用模板，无需为每个角色重新制作。

模板自带一次性的语音播放。必杀技演出的切入、停留、切出、人物动作、亮斩线和背景速度线全部使用固定速度；一倍、三倍以及演出途中切换战斗倍速，都不会改变演出的节奏。语音保持原音高、原时长；播放到中间停留点时会暂停动画时间轴，速度线继续移动，按剩余语音时长提前恢复退场时间轴，让最后约0.22秒语音与擦除动画重叠，避免整句结束后再额外等待退场。视觉擦除完成后若语音仍有很短的尾音，会保持音频播放至结束再回收场景。语音导入应关闭循环。普通攻击特效仍跟随战斗倍速。演出自身不加全屏暗幕，不占用鼠标或键盘焦点，也不负责伤害/AP结算。
