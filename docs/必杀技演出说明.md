# 必杀技演出：卡牌破界共用模板

兰斯必杀1、里克必杀1、谦信必杀1继承 `scenes/cut_in_card_burst_template.tscn`，以 `scripts/skill/cut_in_card_burst.gd` 为基础。演出依次为：实际出手卡牌快速翻起、放大 → 卡面发光裂开并向两侧展开 → 立绘冲出与短暂残影 → 背景 bar 和速度线展开 → 刀光退场 → 战斗原有技能特效与命中结算。演出没有人物名、技能名等额外文字，立绘保持素材本身的亮度。谦信必杀1通过独立继承脚本定制背景，见下文。谦信必杀2为独立的脸部长条玻璃碎裂演出。

## 技能配置

`data/skills.txt` 固定18个字段，第6字段是双引号包裹的演出名称，紧接特效名。

| 演出名称 | 对应场景 | 当前技能 | 色调 |
| --- | --- | --- | --- |
| 兰斯必杀1 | `assets/cut_ins/兰斯必杀1.tscn` | 21 兰斯重击 | 绿色 |
| 里克必杀1 | `assets/cut_ins/里克必杀1.tscn` | 原演出保留，可按第6栏名称选用 | 红色 |
| 里克必杀2 | `assets/cut_ins/里克必杀2.tscn` | 1005 拜拉威（沿用当前技能表选择） | 赤黑曲面长条、锋利赤字、低压兜帽与暗藏眼窝、不对称破布下摆、卡牌同步碎裂 |
| 谦信必杀1 | `assets/cut_ins/谦信必杀1.tscn` | 原演出保留，可按第6栏名称选用 | 深蓝／靛蓝、冷白、金色 |
| 谦信必杀2 | `assets/cut_ins/谦信必杀2.tscn` | 51 军神连击（沿用当前技能表选择） | 中央上下展开的脸部长条、卡牌与玻璃同步碎裂、金边 |

```text
{ 21, "兰斯重击", 1, 1, "", "兰斯必杀1", 3, 1, 300, 0, 0, 0, 0, 0, "", 1, 1, "攻击(3倍)" };
```

只填文件名，不填目录或 Godot 路径，也接受 `.tscn` 后缀。`""` 表示不播放，技能类型和“大招”字段不会补默认演出。不存在的名称、错误根节点、缺少动画或循环动画会警告并跳过，技能继续正常执行。主动技能、成功触发的自动技能与可执行的敌方技能共用播放流程；被动、失败自动触发及不满足条件的行动不播放。

设置支持“不播放”“每次播放”“仅致命一击播放”。致命判定使用真实规则的独立模拟，包括多段攻击、抗性、加成与条件，不改变随机状态或重复判定自动触发。

## 谦信必杀1：毗沙门天军神背景

只有此场景将根脚本覆盖为 `scripts/skill/上杉谦信/kenshin_bishamonten_cut_in.gd`，继承原脚本；共用场景、动画、卡牌与立绘着色器、角色贴图、位置与冲出动作均不变。兰斯和里克继续使用原脚本。

- `BaseLayer`：四段深蓝／靛蓝渐变、斜向框体与细金边。
- `PatternLayer`：低透明度「毘」战旗、五层宝塔轮廓与菱形暗纹。
- `AuraLayer`：头肩后方淡入的金白放射神轮，全部绘制在立绘背后。
- `SpeedLineLayer`：慢速宽条与快速蓝白细线，少量金线点缀；近景线另画在边缘。
- `FXLayer`：沿撕裂缝向两侧飞散的8片碎片、12个粒子，以及金白扫光和退场刀光。

0.54秒原撕裂音效与0.14秒金白扫光同步。神轮在0.62～1.02秒淡入；立绘于1.10秒稳定，背景保持0.39秒，1.49秒开始退出，1.95秒视觉结束。此场景覆盖 `hold_for_voice()`，不因长语音暂停背景；语音在播放前交给战斗图层，视觉退场后通过 `release_voice_tail()` 交接收尾，攻击特效立即接上，首段伤害仍按原攻击特效命中帧结算。剩余语音保持原音高和音量，完整播完后自行回收；中断演出或离开战斗也会清理。兰斯、里克不使用此交接，保留原有流程。专属暗纹只含装饰性「毘」字，不增加人物名或技能名文字。

## 制作新角色

“谦信必杀2”是独立场景，不继承卡牌破界模板，详见 `docs/谦信必杀2.md`。以下制作步骤针对原有卡牌破界模板。

“里克必杀2”沿用曲面长条的卡牌与碎裂编舞，通过独立脚本定制赤色死神主题，详见 `docs/里克必杀2.md`。里克必杀1及谦信必杀2的场景、脚本和素材不作修改。

1. 在 Godot 中从 `scenes/cut_in_card_burst_template.tscn` 创建继承场景，保存到 `assets/cut_ins/<名称>.tscn`。
2. 设置 `portrait`、`voice` 和 `actor_name`。立绘、语音和角色场景统一放在 `assets/cut_ins/`，例如 `兰斯立绘.png`、`兰斯语音.mp3`、`兰斯必杀1.tscn`；`actor_name` 是卡牌表中的完整名称，仅在没有玩家出手卡牌时生成对应默认卡面。
3. `accent` 控制裂光、光环、残影、背景 bar、碎片与退场刀光的角色色调，沿用共用模板的亮度与层次。立绘原始 RGB 不叠乘角色色。
4. `portrait_width` 按1920×1080逻辑画布控制取景宽度，高度始终按原图比例计算；`portrait_position` 是停留阶段左上角位置，`portrait_focus_x` 是立绘展开的横向中心（0～1）。
5. 透明 PNG 保持 `portrait_black_matte=false`，保留人物内部的黑色细节。纯黑背景素材可设置为 `true`。当前谦信开启，兰斯和里克关闭，着色器不改变立绘原始色彩或导入设置。
   兰斯头发与里克头盔已补全，构图使头部略高于背景 bar 上沿，与谦信保持同样的前后层次；原始立绘备份放在项目外测试目录，导入参数及资源 UID 保留。
6. 在技能 TXT 第6栏填写新场景名称，重新导出更新嵌入 EXE 的内容。

根节点为 `Control`，直属 `AnimationPlayer` 含非循环 `cut_in` 动画。所有角色复用这一条1.95秒时间轴；0.62秒启动语音，通用模板在1.28秒按剩余语音时长暂时停留，速度线继续移动，退场与语音尾段衔接。谦信必杀1的短背景停留规则见专属章节。语音走独立 Voice 总线，由“语音音量”控制，保持原音高；场景会等语音完整结束后回收。

0.54秒卡牌裂开时，`SplitSFX` 一次播放共用的 `assets/cut_ins/卡牌破界.wav`，总长0.22秒。声音以魔法斩击和轻能量 burst 为主体，叠加约30%的撕纸质感；纸张层升音高至1.30倍，削弱1.1 kHz以下的厚重成分，缩短起音和混响，软化5.5 kHz以上高频。斩击层也减少低中频与下坠音调，使声音更清脆。该播放器走 SFX 总线，音量为 -5 dB，由“音效音量”控制，不随语音设置或战斗倍速改变。新角色继承模板即可沿用声音和触发时机。

战斗将实际出手卡牌交给场景，完整卡面在透明子视口中以双倍分辨率只渲染一次，再拆为左右两半；原出手卡牌隐藏，避免叠影，命中后由战斗恢复卡牌槽位。子视口与残影都随场景回收。所有动态控件不接收鼠标和键盘焦点，右键仍由战斗在 GUI 前处理共享 `ui_cancel`。

必杀演出动作、停留、速度线与语音不受战斗倍速影响。演出不扣额外 AP、不增加行动、连击或伤害结算。技能特效、命中结算及连击间隔继续由 `BattlePresentation` 和 `BattleState` 管理。

导出预设包含全部 Godot 资源。演出源码、场景与运行素材属于游戏项目；录制脚本、截图、视频、日志与验证报告统一放在项目外 `F:/RanceX Slay The Spire/test`。
