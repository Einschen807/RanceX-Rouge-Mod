# 脚本目录结构

所有游戏脚本位于 `scripts/` 的功能子目录，目录根部不再平铺脚本。场景、素材和 TXT 数据保持原有位置。移动脚本时必须同时移动同名 `.gd.uid`，更新场景、继承路径、自动加载与文档中的文件引用。

| 目录 | 内容 |
| --- | --- |
| `scripts/monster/` | 怪物目录加载和共用怪物工具 |
| `scripts/monster/斗神Σ/` | 斗神Σ专用瞄准逻辑、准星和自定义技能分派 |
| `scripts/monster/岩石G/` | 岩石巨像（识别名岩石G）坚硬外壳开局配置与被动规则分派 |
| `scripts/aid/` | 援助TXT（`data/aids.txt`）目录与各层起点的援助界面（开局选项） |
| `scripts/event/` | 事件TXT、变量绑定、指令序列、事件界面、选项按钮与选项悬停预览（遗物说明框／诅咒卡） |
| `scripts/shop/` | 商店界面、库存、管理与美术辅助；主题商店「米莉的小店」（`milli_shop_screen.gd`） |
| `scripts/map/` | 地图生成、主题权重配置、入层主题横条、路线、节点、纸张背景与地图界面 |
| `scripts/battle/` | 共用战斗状态、回合、演出、预测、快照、支援、异常、护盾、状态按钮与能力／诅咒窗口及战斗UI |
| `scripts/troop/` | 部队状态、编制、升级、附魔选择、快照与编制UI辅助 |
| `scripts/card/` | 卡牌数据库、卡牌控件、卡牌附魔（`card_enchantments.gd`）与升级预览差异标色 |
| `scripts/skill/` | 共用技能运行、编号基础效果、卡牌设计的自定义分派、多属性、条件及演出目录 |
| `scripts/skill/上杉谦信/` | 上杉谦信专用必杀演出 |
| `scripts/relic/` | 遗物数据库、触发规则、宝箱、物品卡遗物选择、百科与HUD |
| `scripts/curse/` | 诅咒TXT（`data/curses.txt`）、诅咒效果规则与编制界面的诅咒物品卡 |
| `scripts/treasure/` | 卡牌宝箱、奖池、奖励与战利品界面 |
| `scripts/run/` | 本局流程、自动存档、流程数据池与失败界面 |
| `scripts/title/` | 标题画面、标题按钮与标题音频时间线 |
| `scripts/encyclopedia/` | 百科入口与叠加菜单 |
| `scripts/settings/` | 共用设置、原版设置界面与窗口设置 |
| `scripts/audio/` | 全局BGM与通用UI音效 |
| `scripts/animation/` | 共用原版FLAT播放器与粒子发射器 |
| `scripts/ui/` | 通用按钮与位图数字 |
| `scripts/core/` | 共用记录解析与画面切换 |
| `scripts/debug/` | 调试控制台与命令补全（`console_suggestions.gd`：输入时在输入框上方列出匹配的命令与参数，命令按前缀／用法文字匹配，卡牌、遗物、诅咒、附魔、怪物、事件、遗物池等参数按包含关系模糊匹配；↓↑选择，Tab、点击或在选中项上按Enter补全，右键／Esc先关闭补全列表） |

## 怪物专用脚本

卡牌强化选择和比较界面位于 `scripts/troop/card_upgrade_screen.gd`，由控制台与休息点共用，规则见[卡牌强化规则](卡牌强化规则.md)。卡牌附魔界面 `scripts/troop/card_enchant_screen.gd` 继承该界面，规则见[卡牌附魔规则](卡牌附魔规则.md)。

怪物专用脚本按 TXT 中的唯一识别名建立独立目录：`scripts/monster/<怪物唯一识别名>/`。专用技能分派、状态、选人规则和专用显示都放在该怪物目录中，共用战斗结算留在 `scripts/battle/`。当前斗神Σ与岩石G的独立实现为：

```text
scripts/monster/
├── monster_catalog.gd
├── 斗神Σ/
│   ├── battle_doushin_targets.gd
│   ├── battle_target_reticle.gd
│   └── doushin_skill_effects.gd
└── 岩石G/
    └── rock_g_skill_effects.gd
```

斗神Σ的专用技能ID由 `scripts/skill/skill_custom_effects.gd` 转发至 `DoushinSkillEffects`，既有技能效果与编号保持原样；岩石G的9922、9924同样转发至 `RockGSkillEffects`。其他怪物目前通过 `data/monsters.txt`、`data/monster_behaviors.txt` 与共用技能配置运行，没有独立脚本；需要专用逻辑时，在各自目录新增实现。新增技能效果仍须先确定使用编号基础效果还是自定义技能ID接口。

脚本文件名和原有 `class_name` 保留，跨功能依赖继续使用现有类名。测试、迁移清单、日志、截图和临时导出均存放在项目外的 `F:/RanceX Slay The Spire/test/`。
